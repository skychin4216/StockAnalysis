## 一、StockDataFacade — 統一數據門面

### 問題
數據獲取邏輯分散在多處（`StockAnalysisAgent` 的 3 個 Tool 類、`StockQueryEngine`、`ChatAgent`、Pipeline 各 Agent），沒有統一的數據層。

### 解決方案
新建 `stock/data/StockDataFacade.kt`，提供統一接口：

| 方法 | 數據源優先級 | 用途 |
|------|------------|------|
| `getRealtimeQuote(code)` | 新浪→騰訊→東方財富（並行） | 實時行情 |
| `getFundamentalInfo(code)` | 東方財富 API → 本地 DB | 基本面 |
| `getHistoricalSnapshots(code, days)` | 本地 DB（含新鮮度檢查） | 歷史快照 |
| `getFundFlow(code, days)` | 本地 DB（含新鮮度檢查） | 資金流向 |
| `getAnalysisData(code, days)` | 一鍵獲取以上全部 | Agent 分析 |

### 修改的文件
- **新建** `stock/data/StockDataFacade.kt`
- **重構** `agent/stock/StockAnalysisAgent.kt` — 刪除 `TechnicalAnalysisTool`、`FundamentalAnalysisTool`、`FundFlowTool` 三個內部類，`analyze()` 改用 `StockDataFacade.getAnalysisData()`，556 行精簡到 323 行
- **新增** `StockAnalysisAgent.buildAnalysisPrompt()` — 將 `StockAnalysisData` 四維度數據格式化為 prompt

## 二、Agent Pipeline 數據注入

### 問題
專家模式 Pipeline 的 `buildStepPrompt` 只注入前序步驟的文字結果，沒有注入實時行情、基本面、技術面、資金面數據。Agent 2（產業鏈賣水人選股）因為看不到數據，所有打分返回 0，`totalScore(0) < 40` 導致標的被淘汰，顯示「未通過流水線」。

### 解決方案
1. `PipelineContext` 新增 `stockData` 字段
2. `runPipeline` 啟動時通過 `StockDataFacade.getAnalysisData()` 獲取數據
3. `buildStepPrompt` 注入實時行情、基本面、技術面、資金面
4. 如果所有打分為 0（數據不足），跳過該步驟而非淘汰標的

### 修改的文件
- `agent/pipeline/PipelineResult.kt` — `PipelineContext` 新增 `stockData` 字段
- `agent/pipeline/AgentPipelineOrchestrator.kt` — `runPipeline` 獲取數據、`buildStepPrompt` 注入數據、打分 0 跳過邏輯
- `agent/pipeline/PipelineResultFormatter.kt` — 數據不足時顯示「跳過篩選」

## 三、StockAnalysisAgent Prompt 修復

### 問題
重構後 `analyze()` 的 prompt 丟失了 JSON 格式說明和評分標準，且 `sendMessageStreamJson` 的 `systemPrompt` 沒有包含數據。

### 解決方案
- `systemPrompt` 改為 `buildSystemPrompt() + 數據`（完整的格式說明 + 數據）
- `messages` 改為包含分析指令的用戶消息
- 類型修復：`map { it.close }` → `map { snap: DailySnapshotEntity -> snap.close }`（避免與 `Closeable.close()` 衝突）

## 五、東方財富 API 解析修復

### 問題
東方財富搜索 API（`searchapi.eastmoney.com/api/suggest/get`）返回的是 JSON 對象 `{"QuotationCodeTable":{"Data":[...]}}`，不是 JSON 數組。代碼用 `JSONArray(body)` 解析崩潰。

### 解決方案
修復解析邏輯，正確處理 `QuotationCodeTable.Data` 格式：

```kotlin
val arr = try {
    val root = JSONObject(body)
    if (root.has("QuotationCodeTable")) {
        root.getJSONObject("QuotationCodeTable").getJSONArray("Data")
    } else if (root.has("Data")) {
        root.getJSONArray("Data")
    } else null
} catch (_: Exception) {
    try { JSONArray(body) } catch (_: Exception) { null }
}
```

### 修改的文件
- `stock/data/StockDataFacade.kt`
- `news/HotSectorNewsUpdater.kt`

## 六、量化選股報告修復

### 問題
「量化選股 → 數據 → 執行策略報告」提示「暫無量化選股歷史數據」。

根因：`saveBacktestData()` 寫入 `strategyPredictionDao` 表，但 `showScanHistory()` 從 `dailyPeriodResultDao` 表讀取且過濾 `strategyId == "STRATEGY_SCAN"`。兩個不同的表，永遠查不到數據。

### 解決方案
`saveBacktestData` 同時寫入 `dailyPeriodResultDao`，使用 `STRATEGY_SCAN` 作為 strategyId。

### 修改的文件
- `ui/StrategyListFragment.kt`
