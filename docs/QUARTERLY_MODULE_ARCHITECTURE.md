# 季度环比分析模組（Quarterly Comparison Module）

## 總體架構

季度环比模組從東方財富 API 獲取最近兩個完整季度的單季財報數據，自動計算環比增速並判定連續趨勢，為 Pipeline 的 Agent 2（財報核驗）提供量化評分依據。

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                        季度环比模組總覽                                      │
│                                                                             │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  東方財富 API                                                        │   │
│  │  reportName=RPT_F10_FINANCE_MAINFINADATA                            │   │
│  │  columns=REPORT_DATE, REPORT_TYPE, PARENTNETPROFIT, TOTALOPERATEREVE│   │
│  │         DJD_DPNP_QOQ, DJD_DEDUCTDPNP_QOQ, DJD_TOI_QOQ               │   │
│  └────────────────────────┬────────────────────────────────────────────┘   │
│                           │                                                │
│                           ▼                                                │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  QuarterlyComparisonProvider.fetch(stockCode)                       │   │
│  │                                                                     │   │
│  │  1. 拉取最近6條財報記錄（覆蓋1年+）                                 │   │
│  │  2. 篩選最近兩個非年報季度（一季報/中報/三季報）                      │   │
│  │  3. 提取 API 環比數據（DJD_DPNP_QOQ 等）                            │   │
│  │  4. API 缺失時手動計算：(當季-上季)/|上季|×100%                    │   │
│  │  5. 趨勢判定（連續2季為基準）                                       │   │
│  │  6. 評分調整（+5 / -10 / +2 / -5 / 0）                              │   │
│  └────────────────────────┬────────────────────────────────────────────┘   │
│                           │                                                │
│                           ▼                                                │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  QuarterlyComparisonResult                                          │   │
│  │  ┌─────────────┐  ┌─────────────┐                                   │   │
│  │  │ latest      │  │ previous    │                                   │   │
│  │  │ (最新季度)   │  │ (上一季度)   │                                   │   │
│  │  └─────────────┘  └─────────────┘                                   │   │
│  │                                                                     │   │
│  │  netProfitQoQ: Double      ← 歸母淨利潤環比(%)                      │   │
│  │  revenueQoQ: Double        ← 營收環比(%)                            │   │
│  │  deductNpQoQ: Double       ← 扣非淨利潤環比(%)                      │   │
│  │  trend: QuarterlyTrend     ← 連續趨勢判定                           │   │
│  │  scoreAdjustment: Int      ← 評分調整建議                           │   │
│  │  isFresh: Boolean          ← 數據新鮮度(<30天)                      │   │
│  └────────────────────────┬────────────────────────────────────────────┘   │
│                           │                                                │
│                           ▼                                                │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  formatForAgentInjection()                                          │   │
│  │  Markdown 表格 → 注入到每步 Agent 的 SystemPrompt                   │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 數據流

```
┌─────────────────────────────────────────────────────────────┐
│                     季度环比數據流                            │
│                                                             │
│  AgentPipelineOrchestrator.execute()                        │
│       │                                                     │
│       ├── 調用 QuarterlyComparisonProvider.fetch(stockCode)  │
│       │   │                                                 │
│       │   ├── HttpClientProvider.realtimeClient 請求東財 API │
│       │   │   URL: datacenter-web.eastmoney.com             │
│       │   │   參數: pageSize=6, sortColumns=REPORT_DATE     │
│       │   │                                                 │
│       │   ├── 解析 JSON → List<QuarterlyFinanceData>        │
│       │   │   過濾年報，保留一季報/中報/三季報               │
│       │   │                                                 │
│       │   ├── 取最近兩條 → latest + previous               │
│       │   │                                                 │
│       │   ├── 計算/提取環比數據                             │
│       │   │   優先使用 API 的 DJD_DPNP_QOQ                  │
│       │   │   缺失時手動計算                                │
│       │   │                                                 │
│       │   ├── 趨勢判定（需3個季度數據）                      │
│       │   │   連續2季正 → ACCELERATING_IMPROVEMENT         │
│       │   │   連續2季負 → ACCELERATING_DECLINE             │
│       │   │                                                 │
│       │   └── 評分調整映射                                  │
│       │                                                     │
│       ├── 存入 PipelineContext.quarterlyComparison           │
│       │                                                     │
│       └── buildStepPrompt() 注入到每步 SystemPrompt          │
│           所有 Agent 均可讀取季度环比數據                    │
└─────────────────────────────────────────────────────────────┘
```

## 趨勢判定邏輯

```
┌─────────────────────────────────────────────────────────────┐
│                    趨勢判定流程圖                             │
│                                                             │
│  輸入: 最近3個季度的 netProfitQoQ 值                          │
│                                                             │
│         Q(n)     Q(n-1)    Q(n-2)                           │
│          │         │         │                              │
│          ▼         ▼         ▼                              │
│       最新環比    上季環比   上上季環比                       │
│                                                             │
│  ┌─────────────────────────────────────────────┐            │
│  │ 條件1: Q(n)>0 且 Q(n-1)>0 且 數據足夠?      │            │
│  │ → ACCELERATING_IMPROVEMENT (+5分)           │            │
│  │   "連續2季環比上升，經營加速改善"             │            │
│  └─────────────────────────────────────────────┘            │
│                         │ 否                                │
│                         ▼                                   │
│  ┌─────────────────────────────────────────────┐            │
│  │ 條件2: Q(n)<0 且 Q(n-1)<0 且 數據足夠?      │            │
│  │ → ACCELERATING_DECLINE (-10分)              │            │
│  │   "連續2季環比下降，經營頹勢明顯"             │            │
│  └─────────────────────────────────────────────┘            │
│                         │ 否                                │
│                         ▼                                   │
│  ┌─────────────────────────────────────────────┐            │
│  │ 條件3: Q(n)>0 ?                             │            │
│  │ → SINGLE_IMPROVEMENT (+2分)                 │            │
│  │   "單季環比改善，需觀察後續延續性"            │            │
│  └─────────────────────────────────────────────┘            │
│                      │ 否                                  │
│                      ▼                                      │
│  ┌─────────────────────────────────────────────┐            │
│  │ 條件4: Q(n)<0 ?                             │            │
│  │ → SINGLE_DECLINE (-5分)                     │            │
│  │   "單季環比下滑，需關注是否持續"              │            │
│  └─────────────────────────────────────────────┘            │
│                      │ 否                                  │
│                      ▼                                      │
│  ┌─────────────────────────────────────────────┐            │
│  │ → FLAT (0分)                                │            │
│  │   "環比平穩，無明顯趨勢"                     │            │
│  └─────────────────────────────────────────────┘            │
└─────────────────────────────────────────────────────────────┘
```

## 支持的季度對比

| 當前季度 | 對比季度 | 說明 |
|----------|----------|------|
| 2026Q1 | 2025Q4 | 跨年對比（年報→一季報） |
| 2026Q2 | 2026Q1 | 常規季度對比 |
| 2026Q3 | 2026Q2 | 常規季度對比 |
| 2026Q4 | 2026Q3 | 常規季度對比 |

**實現原理**：API 返回的 `REPORT_TYPE` 為「一季報」「中報」「三季報」「年報」。模組自動過濾年報，保留單季度數據進行環比計算。無論是哪兩個相鄰季度，計算邏輯完全一致。

## 數據新鮮度

```
┌─────────────────────────────────────────────────────────────┐
│                    數據新鮮度判定                            │
│                                                             │
│  UPDATE_DATE / NOTICE_DATE 距今天數                          │
│                                                             │
│       < 30天 ──→ isFresh = true（綠色標識）                  │
│      >= 30天 ──→ isFresh = false（黃色標識，提示數據較舊）   │
│                                                             │
│  實際場景:                                                   │
│  - 季報密集期（4月/8月/10月）：數據通常 < 7天，fresh        │
│  - 季報空窗期（5-7月/11-1月）：可能 > 30天，stale           │
└─────────────────────────────────────────────────────────────┘
```

## 緩存策略

```
┌─────────────────────────────────────────────────────────────┐
│                     5分鐘內存緩存                             │
│                                                             │
│  key: stockCode (純數字，如 "603986")                        │
│  value: Pair<QuarterlyComparisonResult, timestamp>          │
│                                                             │
│  fetch() 邏輯:                                               │
│       │                                                     │
│       ├── 檢查緩存是否存在且未過期(<5分鐘)                    │
│       │   ├─ 是 → 直接返回緩存結果                           │
│       │   └─ 否 → 繼續拉取                                  │
│       │                                                     │
│       └── 寫入緩存並返回                                     │
│                                                             │
│  目的: 同一股票短時間內不重複請求 API，降低網絡負載           │
└─────────────────────────────────────────────────────────────┘
```

## 格式化輸出示例

```markdown
【季度环比數據】（數據截至: 2026Q1）
| 指標 | 2026Q1 | 2025Q4 | 環比變化 | 趨勢 |
|------|--------|--------|---------|------|
| 單季歸母淨利潤 | 14.61億 | 5.64億 | +158.7% | ⬆️ |
| 單季營業收入 | 41.88億 | 23.74億 | +76.6% | ⬆️ |
| 綜合判定 | — | — | — | 加速改善 |

趨勢結論: 連續2季環比上升，經營加速改善
評分調整: +5分 — 連續2季環比上升，經營加速改善
```
