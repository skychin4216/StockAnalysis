## 核心組件

### StockDetailFragment

`com.chin.stockanalysis.ui.StockDetailFragment`

- **職責**：股票詳情頁，展示 K線/行情/AI分析/機構評級/趨勢圖/基本面/新聞
- **數據獲取**：`StockDataFacade.getAnalysisData()` 獲取完整數據
- **AI 分析**：`runAiAgents()` 調用 `UnifiedAgentRunner.run(MODE_PIPELINE)`
- **趨勢圖**：`buildTrendImagesSection()` — 從 assets/trend_images 加載，支持 ViewPager2 全屏滑動

### ChatTabFragment

`com.chin.stockanalysis.ui.ChatTabFragment`

- **職責**：AI 對話主頁，支持多輪對話 + Pipeline 進度實時顯示
- **消息類型**：Text / Image / Error / Stream / StepProgress
- **Pipeline 集成**：通過 `PipelineChatAdapter` 封裝 Pipeline 調用，實時回調每步進度

### 消息類型體系

```
┌─────────────────────────────────────────────────────────────┐
│                     Message 類型體系                          │
│                                                             │
│  enum class MessageType {                                   │
│      TEXT,       ← 普通文本消息                             │
│      IMAGE,      ← 圖片消息                                 │
│      ERROR,      ← 錯誤提示                                 │
│      STREAM,     ← 流式輸出（逐字顯示）                      │
│      STEP_PROGRESS  ← Pipeline 步驟進度（新增）             │
│  }                                                          │
│                                                             │
│  data class Message(                                        │
│      id: String,                                            │
│      type: MessageType,                                     │
│      content: String,                                       │
│      isUser: Boolean,                                       │
│      timestamp: Long,                                       │
│      stepProgress: StepProgress?  ← Pipeline 專用           │
│  )                                                          │
└─────────────────────────────────────────────────────────────┘
```
