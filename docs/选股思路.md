# 选股思路（Sector Picks · 板块联动选股）

> CodeBuddy 个股挖掘方法论（2026-09-09 定稿 v1）。
> 配套 skill：`.codebuddy/skills/sector-picks/SKILL.md`；上游板块分析：`docs/板块分析思路.md`。
> 目标：**给定一个被验证的板块（生命周期≤鱼身），筛出"弹性大 × 有预期 × 估值合理 × 适配当前大盘（震荡向下→中小盘优先）"的个股清单**，含买入区间、弹性测算、止损与证伪线。

---

## 0. 六维漏斗（每只票过六关）

```
板块已定 → ①卡位(龙头/弹性) → ②基本面(财务排雷+盈利质量)
        → ③估值(PE失真拆解+安全垫) → ④资金(主力动向确认)
        → ⑤形态(趋势+低吸区) → ⑥大盘适配(仓位+纪律) → 输出个股卡
```

**先选板块后选股，不在弱势大盘里逆势做弱势板块。**
**个股只是板块逻辑的载体：板块逻辑证伪（价格跌破锚/库存累积/政策转向），再好看的个股形态也走人。**

---

## 1. 卡位分析：龙头 vs 弹性

### 1.1 两条腿走路（元宝草甘膦案例）
- **正宗龙头（稳）**：成本曲线最左侧、产能/市占第一、业绩有支撑。如草甘膦——兴发集团（配套完整、草甘膦 18 万吨+磷化工）、广信股份（成本低）。稳但市值大弹性小。
- **弹性小票（博）**：小市值 + 单一品种高敏感。弹性排序看**弹性贡献度**（见 §2），如广信股份 PB 1.01 破净小盘弹性高于扬农化工大龙头。

### 1.2 弹性三问
1. 涨价 1 个点，利润增厚占市值比重多少？（元宝法：涨 1 千元 → 多赚 = 产能(万吨) × 0.1 亿元）
2. 产能/股本比是否极致（小股本 + 大产能 = 高弹性）？
3. 若 2025 年亏过（有减值），恢复期的 ROE 弹性是否被忽视？（利空出尽→戴维斯双击候选）

> 例：草甘膦 2026-09 现价 2.57 万/吨、龙头吨净利 4700-5700 元；兴发弹性 = 原药吨价每涨 1 千元 → 净利 +3.4 亿/年 → 相对市值 376 亿 ≈ +0.9%。弹性大但市值中等。小盘广信 PE 15.8 弹性更大。

## 2. 财务排雷 + 盈利质量核查（多空反转前必查）

来自《上市公司财务健康完整核查思路》，执行顺序：**粗筛 → 盈利质量 → 偿债 → 现金流 → 周转 → 隐形风险 → 横纵对比**。

### 2.1 粗筛（20 秒排除）
- 审计意见非标准无保留 → 直接排除；
- 财务造假迹象：货币资金高 + 有息负债高（"存贷双高"）、经营现金流连续两年与净利背离、应收账款增速 > 营收增速 2 倍；
- 质押率 > 50%、商誉/净资产 > 30%、频繁更换审计机构。

### 2.2 盈利质量（核心）
- 净利正 ≠ 质量好：看 **扣非净利**（剔一次性）；
- 毛利率趋势：涨价行情下毛利率若不动 → 涨价没落到上市公司（卖的是原料/贸易）；
- ROE 质量：杜邦拆解——靠周转/杠杆 vs 靠净利率；
- 周期股看**产能利用率 + 在建工程**（景气期大扩产 = 下一轮风险）。

### 2.3 偿债与现金流
- 短期借款/现金覆盖、流动比率；
- 经营净现金流 > 净利（优质）；收现比 > 1；
- 资本开支与折旧匹配，防"利润造在折旧外"。

### 2.4 周期股特别项
- 景气底部区域：看 **PB + 破产风险**（净债务/市值），不是看 PE（PE 在底部极高）；
- 顶部区域：PE 低是**陷阱**（周期顶利润峰值算出的低 PE），看 PB 分位与资本开支。

## 3. 估值筛选（中盘优先 + PE 失真拆解）

### 3.1 市值档位（震荡向下大盘，用户偏好）
| 档 | 市值 | 定位 | 策略 |
|---|---|---|---|
| 小盘 | 30-80 亿 | 高弹性题材 | 快进快出，仓位小，警惕退潮 A 杀 |
| **中盘（主推）** | **80-300 亿** | 机构能上量、又不至于撬不动 | **弹性与安全边际的平衡区** |
| 中大盘 | 300-600 亿 | 主线龙头 | 趋势仓，弹性下降 |
| 大盘 | >600 亿 | 权重/防御 | 只作大盘信号或配置 |

### 3.2 PE/PB 判据（结合板块生命周期）
- 周期成长股（草甘膦/磷肥）：静态 PE < 25 且 PB < 2.5 为健康；破净（PB<1.1）是小盘安全垫信号（广信股份 PB 1.01）；
- 题材成长股（种业）：PE 是次要（种业普遍 PE>80），**用市梦率 + 资金 + 扩散位置**定价，仓位减半、止损收紧；
- **动态 PE < 静态 PE 且方向明确**（产能释放/涨价落地）→ 动态估值便宜是真的（化肥/化工适用）；
- 动态 PE 为负/异常 → 拆解四因（亏损/季节性/一次性/高基数，见板块分析 §3.3），换静态 PE 或全年预期（北大荒 Q4 确认利润 → 滚动 PE 失真，看静态 21 倍）。

### 3.3 安全边际加分项
PB 接近历史低分位、股价接近定增/员工持股价、破净、股息率>2%（防御底仓用）。

## 4. 资金验证（主力动向，来自《主力資金動向判斷》）

### 4.1 三层确认
1. **主力净流入窗口**：3/5/20 日主力资金（东财 f62，行业/概念层面用 `_sector_fundflow.py`）；
2. **量价确认**：突破日放量（>5日均量 1.5 倍）、回踩缩量（<5日均量 0.6 倍）、上涨不放量=假突破；
3. **行为信号**：北向/ETF 份额、龙虎榜游资 vs 机构席位、涨停梯队完整度（龙头+跟风连板）。

### 4.2 腾讯兜底口径（东财断时）
`qt.gtimg.cn/q=` 批量行情字段（公认映射）：
`f32 涨跌% / f38 换手 / f44 流通市值(亿) / f45 总市值(亿) / f46 PB / f47 涨停 / f48 跌停 / f49 量比 / f53 静态PE`
日K：`fetch_tencent(secid, beg, end)`（backtest_guangmo 模块），算 5/10/20 日动量 + MA20/60 + 距 60 日高点。

### 4.3 资金与价格背离警示
价创新高而主力连续净流出 → 出货嫌疑；价横盘缩量而主力悄悄流入 → 洗盘/吸筹，观察突破。

## 5. 形态与周期匹配（来自《全流程闭环》）

1. **看大周期定位置**：月线/周线判断板块与个股在长周期的位置（底部右侧 vs 高位滞涨）；前瞻/中长标的多拉一步 **250 日涨幅 + 距 250 日高点**——"距 60 日高 -50%"可能是年涨 3 倍后的腰斩（假低位，如 2026-09 半导体存储），也可能是刚走出底部右侧（真低位，如同期猪链）；
2. **均线定趋势**：MA20>MA60 且价站上 = 多头（可持有）；纠缠 = 等方向；空头 = 不接；
3. **量价验证**：底部放量突破颈线（>20日量 1.5 倍）为启动信号；缩量回踩 MA20 不破 = 低吸点；
4. **短中线匹配**：短线用 5/10 日动量+情绪，中线用 20/60 日均线与基本面，**不做周期错配**（拿中线的票做短线、拿题材的票做长线）；
5. 目标/止损：以支撑位下 3-5% 为止损，以阶段压力/估值上沿为目标，盈亏比 > 2:1 才参与。

## 6. 大盘适配与仓位纪律（震荡向下环境的做法）

当前基准（2026-09-09）：上证纠缠、科创50/沪深300/创业板空头排列、沪深300 空头 → **低吸门控关闭**。

- 大盘空头/纠缠：只做「板块逻辑硬 + 个股位置低 + 中小盘」的精选，单票 ≤ 1.5 成，总仓 ≤ 3 成；
- 低吸不追高：鱼身票等回踩 MA10/MA20 或涨停次日缩量分歧再上；鱼尾票不参与；
- 分档建仓：首仓 1/3，验证（放量突破/回踩不破）后加 1/3，破位止损不留恋；
- 行情如跌破板块证伪线（价格锚/龙头破位），无条件降档。

## 8. 一页纸 SOP（每次执行照此跑）

1. 收上游板块卡（sector-hunter）→ 确认板块生命周期 ≤ 鱼身；
2. 圈候选池：板块成分里找「正宗+弹性」两个梯队各 2-4 只，剔除质押/商誉/审计雷（§2 粗筛）；
3. 拉数据：腾讯 `q=` 估值字段 + `fetch_tencent` 日K 动量/均线（§4.2），东财可用则补主力资金 f62；
4. 估值判据：市值 80-300 亿优先，周期股静态 PE<25 & PB<2.5，破净加分，PE 失真拆解（§3.2）；
5. 形态与量价：多头排列 + 20日涨幅 <50%（未鱼尾）优先；**前瞻/中长标的多做 250 日位置双校验**（防 60 日窗口幻觉）→ 给低吸区与止损线；
6. 大盘适配：空头/纠缠 → 总仓 ≤3 成、单票 ≤1.5 成、低吸纪律；
7. 输出个股卡 ×3-6 只，标注数据截至与口径 + 免责声明。
