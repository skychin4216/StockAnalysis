總覽5 層架構

點擊任一層級卡片可跳轉到對應子系統的詳細視圖。整體數據流：用戶意圖自上而下傳遞，數據讀取與持久化自下而上返回。

UI 層5 Tab Fragment

MainActivity 使用 ViewPager2 承載 5 個 Tab Fragment，StockDetailNavigator 統一處理股票詳情跳轉，CrossTabBus 基於 Flow 實現跨 Tab 事件通信。點擊 Agent 模塊可跳轉到 Agent 編排層視圖。

Agent 編排層確定性路由 · 多 Agent 協作

IntentRouter 使用確定性規則路由（無 LLM），支持 4 種意圖。深度分析分 3 階段：ScoutTask 量化偵察 → 並行 LLM 分析與風控 → V2 決策矩陣 → 報告匯總。點擊 Strategy 模塊可跳轉到 Strategy 視圖。

Strategy / Pipeline 層DAG 拓撲引擎 · 6 Tier

UseCaseLoader 讀取 XML 配置，PipelineXmlParser 解析為 DAG，DagPipeline 使用 Kahn 拓撲排序分層並行執行。支持 fail-fast。點擊 Data 或 Database 模塊可跳轉到對應視圖。

Data Provider 層三源並行 · 智能緩存

StockDataFacade 作為統一門面，提供三級降級策略。IntentProcessorChain 識別用戶意圖，MultiSourceStockRepository 三源並行獲取數據。點擊 Database 模塊可跳轉到 Database 視圖。

Database 層Room v14 · 17 表 · 4 域

Room Database v14，17 張表按業務域分為 4 組。遷移從 v1 逐步演進到 v14。所有表的外鍵引用統一指向 stock_basics.code，StockDataFacade 負責統一讀寫。
