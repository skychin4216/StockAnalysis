# 板块分析思路（Sector Hunter · 板块猎手）

> CodeBuddy 板块挖掘方法论（2026-09-09 定稿 v1；同日升级 v1.1：新增「前瞻潜伏」轨 + 250 日年线位置验证，防 60 日窗口幻觉）。
> 配套 skill：`.codebuddy/skills/sector-hunter/SKILL.md`；选股下游：`docs/选股思路.md`。
> 目标：**每日三次（早盘前 / 午盘休 / 尾盘后）结合实时情报，找到"可能启动的板块"与"周期低位板块"，识别炒作所处生命周期（底部/初升/鱼身/鱼尾），输出可验证的板块候选清单。**

---

## 0. 核心思想

炒板块 = 炒「催化 × 预期 × 资金」，三件事按顺序到位才是行情：

1. **催化**（为什么涨）：政策 / 天气与灾害 / 商品涨价 / 订单放量 / 技术突破 / 机构集体看多。
2. **预期**（涨多少）：市场开始定价"将要发生的验证事件"，而不是当前报表。
3. **资金**（谁在买）：主力净流入、板块成交额放大、龙头涨停梯队、ETF 份额。

**判断板块行情处于哪个阶段，比判断"会不会涨"更重要**——绝大多数亏损来自把「鱼尾」当「鱼身」追高。

## 1. 情报采集（数据底层，Agent F 职责）

### 1.1 多源矩阵

| 来源 | 抓什么 | 优先级 |
|---|---|---|
| 主流财经媒体（财联社/证券时报/上证报/每经） | 政策、价格、产经要闻 | 高 |
| 国内头部券商研报（中信/中金/华泰/国君/申万/广发/银河） | 行业景气、价格预测、供需测算 | 高 |
| 海外投行报告（高盛/大摩/美银/瑞银/伯恩斯坦） | 大宗定价、目标价、产业格局 | 高 |
| 名人/大佬发言与访谈 | 方向性观点（含分歧警示） | 中 |
| 交易所/官方公告（巨潮） | 业绩预告、经营数据、产能 | 高（验证用） |
| 商品现货价（草甘膦/磷肥/锂/煤/油） | 周期股直接锚 | 高 |
| 龙虎榜 / 涨停板梯队 | 资金攻击方向 | 高 |

### 1.2 采集工具（按可用性排序）

1. `web_search` / `web_fetch`（外网资讯）——**第一优先**；
2. 东财板块资金流 `_sector_fundflow.py`（push2delay，行业 m:90+t:2 / 概念 m:90+t:3，f62 主力净流入）——东财直连被断时退腾讯；
3. 腾讯行情链路（`qt.gtimg.cn/q=` 实时 + `fetch_tencent` 日K，字段映射见选股思路 §4）——**最稳**，东财不可达时用它；
4. 本地缓存 `data/_index_market.json`（四指数）、`_kline_cache.json`（个股日K）、`_last_scan.json`（情报扫描快照：板块轮动 top/快讯/研报聚合）、`_rotation_engine` 轮动缓存；
5. `_market_scan.py`（盘中情报守护）已自动收集板块轮动 top3+催化、快讯、机构研报聚合——**直接读 `_last_scan.json` 复用**。

> 若当日外网全断：退化为「本地行情 + 缓存情报」的动量/资金扫描，产出「纯数据版」板块卡，并标注数据截至日。

### 1.3 情报登记纪律

- 每条催化记录：**事实 + 日期 + 来源 + 对哪条产业链/哪类标的（上游/中游/下游）利好 + 预期强度（强/中/弱）**；
- 区分「已兑现」（涨价落地、订单披露）与「待验证」（窗口临近但数据未出）——草甘膦 9 月就是"预期窗口"，不是"现价主升"（见实战案例）；
- 防二手失真：媒体转引的机构观点，注明"原报告未获取，以转引为限"（煤炭报告教训：同一 PE 分位不同源可差 60 个百分点）。

## 2. 板块生命周期定位（核心技能）

### 2.1 五阶段标尺

| 阶段 | 特征 | 操作含义 |
|---|---|---|
| **底部区** | 商品价/股价长期磨底、跌破成本线、无人问津；估值历史低分位；出现首个"边际改善"催化（限产/出口/政策/库存去化） | 左侧小仓埋伏（周期锚定价：如锂 15 万/吨、草甘膦破 2.45 万、油价>80 化工） |
| **初升期** | 龙头放量首阳/二连板、板块指数站上 MA20、出现赚钱效应但大众将信将疑 | 主仓位介入黄金窗，盯龙头确认 |
| **鱼身/主升** | 涨幅扩散（龙头→二线→小票）、成交额持续放大、机构开始覆盖、研报密集 | 持有/低吸补票，按梯度减仓纪律 |
| **鱼尾** | 小票乱飞、题材扩散到"沾边即涨"、PE 数百倍仍涨停、龙头滞涨 | 只做快进快出或离场；把"弹性故事"当风险提示 |
| **退潮** | 龙头跌停、板块指数跌破 MA20、利好不涨 | 回避，转下一主线 |

### 2.2 客观量化判据（数据可得时）

- **阶段分位**：板块指数/代表股 距 60 日高点回撤、20 日累计涨幅：`20日>+50% 且 距高点<5%` → 鱼身中后段；`龙头PE/PB 历史高分位 + 20日>+80%` → 鱼尾警戒；
- **扩散度**：板块涨停家数、龙头 vs 跟风票涨幅差（差变小=扩散到鱼尾）；
- **估值纪律**：种业/题材股 PE>80 且 PB>5 视为纯情绪（除非有业绩兑现路径）；**PE 为负/失真**要拆原因（见 §3.2）；
- **资金确认**：板块主力净流入（f62）连续为正、成交额占两市比抬升、ETF 份额扩张（煤炭案例：ETF 份额 +25.8% 验证资金流入）。

### 2.3 周期规律速查（来自《全流程闭环》+ 实战校准）

| 板块/品种 | 周期驱动 | 上涨持续期 | 季节/时点规律 |
|---|---|---|---|
| 草甘膦/农药 | 南美播种+春耕+枯水期限产 | 3-6 个月波段 | **12-1月关注、2-4月主升、6-8月南美发货、9月中下-10月南美补库预热**；价锚 2.45/2.6/2.9/3.3 万 |
| 化肥/磷化工 | 粮价→种植面积→化肥需求+磷矿涨价 | 6-12 个月 | 厄尔尼诺/粮价上涨后滞后 1-2 季度受益 |
| 煤炭 | 供给收缩（安监/进口）+冬储 | 6-12 个月 | 动力煤看库存+长协+冬储；焦煤需钢厂利润确认 |
| 黄金 | 美元/降息/避险 | 6-18 个月 | 降息预期升温启动 |
| 有色（铜铝锂） | 全球 PMI/流动性 | 12-24 个月 | 大宗轮动最先启动（有色 T-40 → 化工 T-18 → 石油 T+53 → 煤炭 T+60 → 钢铁 T+131） |
| 稀土 | 政策（出口管制/收储） | 3-12 个月 | 政策发布+新能源需求 |
| 半导体 | 4 年一轮周期+AI/国产替代 | 主升 1.5-2 年 | 传导：终端→设计→代工封测→设备→材料（各滞后 1-3 季度） |
| 医药 | 集采落地+创新药 | 6-18 个月 | 政策明朗+重磅获批 |
| 电力/电网 | 逆周期政策/特高压 | 12-24 个月 | 政策文件+投资规划 |
| 厄尔尼诺农业链 | 天气灾害→粮价/减产 | 参考历史 1-2 个月题材浪 | 米(金健/苏垦) → 种业(隆平/登海) → 农资化肥(滞后) → 农药(草甘膦农时) |

> 周期规律是**概率与节奏指引**，不是精确时间表；必须叠加当期数据（价格/库存/政策）动态修正，不可机械套用。

## 3. 热门板块 vs 周期低位板块的双轨

### 3.1 轨 A：正在启动/主升的热门板块（追势）

判断"主线真伪"（Agent 3 职责）：区分正宗核心 vs 蹭热度假题材——
1. 催化是否指向**实物量/真实需求**（订单、排产、出口量）而非纯口号；
2. 龙头是否有**业绩基础**（近两季净利为正、涨价能落袋）；
3. 估值是否已在定价"明年甚至后年的预期"（光模块 3.2T 2027 放量被提前透支的教训）；
4. 若已在鱼尾（见 §2），再好的逻辑也只做快反不做主仓。

### 3.2 轨 B：周期低位板块（潜伏）

判断"低位三问"（草甘膦案例）：
- **相对历史顶**：现价/顶价 几折？（草甘膦现价 2.57 万 vs 历史顶 8 万 = 3 折）
- **相对近期底**：比 2025 大底高多少？（高 10-12% → 底部上沿，不是地板价）
- **相对成本线**：破没破成本？（现价贴成本、龙头吨利 4700-5700 元 = 下行有底）
- 结论分级：真低位（价格低+股价低，等回踩） vs 假低位（价格低但股价已炒过——"价格低不代表股票便宜"，9/8 草甘膦板块 +4.84% 后板块已不便宜）。

### 3.3 PE 失真的四种拆解（低 PE 筛选前必查）

1. **周期亏损/减值**（和邦生物 2025 减值致 PE 为负）→ TTM 失真，看 PB 与盈利恢复路径；
2. **利润季节性集中**（北大荒 Q4 确认）→ 动态/滚动 PE 出现负值，用静态 PE 或全年预期；
3. **一次性收益**（卖资产/补贴）→ 扣非净利为正才算；
4. **高基数失真** → 看两年复合或环比趋势。

## 4. 大盘环境适配（决策闸门）

先判大盘，再谈板块（与 APK 门控同口径）：

| 大盘状态（四大指数 MA 结构） | 板块参与策略 |
|---|---|
| 共振强势（上证+科创同涨） | 可扩散：主线+补涨一起做，仓位 6-8 成 |
| 权重搭台、成长休整 | 精选主线低吸，5-6 成 |
| 结构行情（科创强、上证弱） | 中小盘题材快进快出，3-5 成 |
| 均线纠缠 / 存量博弈（当前 2026-09-09：上证纠缠、科创50/300/创业板空头） | **少而精**：只挖低位刚启动 + 资金共识主线龙头，3 成内 |
| 防御/空头 | 0-2 成，避险与红利为主；沪深300 空头 = 低吸门控关闭 |

数据入口：`data/_index_market.json`（四大指数）+ `verdict_text()`（`_index_market_chart.py`，与 APK 同规则）。

## 5. 每日三次板块挖掘节奏（对接三次推送）

| 时段 | 产出 | 侧重 |
|---|---|---|
| **早盘前（09:10 前后）** | 「板块晨报」：隔夜消息面（美股/期货/政策）+ 昨日涨停梯队 + 候选板块生命周期更新 + 今日验证清单 | 谁可能启动/延续 |
| **午盘休（12:40 前后）** | 「午间雷达」：上午板块涨幅榜/主力资金 Top、异动确认、上午涨停梯队 | 主线是否被资金验证 |
| **尾盘后（15:15 前后）** | 「尾盘复盘 + 次日预案」：全天板块轮动、龙头收盘形态、涨停封板质量、次日验证点 | 明日跟踪谁 |

每次输出统一两大节：**A. 已启动主线（追势）** + **B. 前瞻潜伏（埋伏）**，均用 §6 卡片格式；并落盘 `data/_sector_hunt_<date>_<时段>.txt` + `docs/sector-hunt/<date>_<时段>.md` 供复盘。

> 每次至少给 1-2 张前瞻潜伏卡（生命周期=底部/初升早段、尚未资金确认、但催化窗口临近），附启动触发器——只汇报已涨的板块对"提前布局"没有增量。

## 7. 一页纸 SOP（每次执行照此跑）

1. **定大盘**：读四指数 MA 结构 → 定仓位档与板块策略（§4）；
2. **采情报**：web 检索各源当日催化（§1），网络断则读 `_last_scan.json` + 本地行情；
3. **筛候选板块**：热门（轨 A：已启动/主升，验证真伪与阶段）+ **前瞻潜伏（轨 B：未启动但催化窗口临近，低位三问）**；
4. **标阶段**：每板块打生命周期标签（§2），剔除鱼尾爆炒、标记初升/鱼身主候选；
5. **年线定乾坤（前瞻专用）**：轨 B 候选必须拉 **250 日涨幅 + 距 250 日高点**，拆穿 60 日窗口幻觉——"距 60 日高 -50%"可能是一年翻 3 倍后的腰斩（假低位，勿左侧接刀），也可能是刚走出底部右侧（真低位，回踩即机会）；案例见 `docs/sector-hunt/2026-09-09_前瞻候选.md`（半导体存储 vs 猪链）；
6. **列验证信号**：A 轨给启动/证伪线；**B 轨给"启动触发器"**（价格/库存/政策/资金的可验证事件+时点），不给现价追入建议；
7. **输出 A 已启动情报卡 ×2-3 + B 前瞻潜伏卡 ×1-2**（§6 两种模板），标注数据截至与口径；
8. **交下游选股**：把 A 轨 Top 板块与 B 轨触发器兑现的板块喂给「选股思路」筛个股（docs/选股思路.md）。

## 8. 数据与口径纪律（煤炭报告教训）

1. 价格/库存：注明口径（港口 vs 产地、八港 vs 九港、指数 vs 报价），只做方向判断不拼精确分位；
2. 估值分位：跨数据库分位差异极大（煤炭 PE 分位 26% vs 85.8%），**只用绝对水平与同源比较**；
3. 数字只给「可核验的公开值」，媒体/第三方样本仅用于解释机制；
4. 每次输出带免责：研究分析，不构成投资建议；以交易所与最新披露为准。
