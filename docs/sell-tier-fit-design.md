# 卖出规则「资产分档 + 已知结果拟合」设计与落地

> 状态：已落地回放侧（smalltools 引擎 + backtest_params.json）；文档记录拟合验证结论与两种正式拟合方案。

## 1. 为什么做资产分档

实证（XML 长线信号，2015-2026 四段 3810 笔，与官方 `simulate_trade` 同口径逐行等价）：

- 现状 9 格矩阵对长线一律 `持有 40 交易日 / 止盈 50% / 止损 -12%`。40 天到期卖出对**高波动题材股**是对的（A 股震荡市卖点），但对**低波动慢牛资产**（银行/黄金/电力/红利/部分煤炭等，买入日 20 日波动率低）是"卖飞"：这类资产趋势久、回撤浅，时间换空间有效。
- 用户实盘观察一致："黄金股/银行股拿住了才挣大钱，40 天就被换掉"。

**落地规则（资产双轨）**：卖出规则按买入标的波动率分两档：

| 档位 | 判定（买入日可用特征，无未来函数） | 规则 |
|---|---|---|
| standard | vol20 ≥ 阈值 或 未配置 lowVol 档 | 现状 9 格矩阵 |
| lowVol | vol20 < 阈值 且 周期配置了 lowVol 档 | 放宽持有 / 去止盈 / 宽止损 |

配置文件：`app/src/main/assets/backtest_params.json` → `sell_rules.长线.lowVol`
（当前落地值由拟合给出，见 §3；结构向后兼容，Kotlin 端忽略未知键仍读旧 9 格）。

引擎改动：`smalltools/_full_cycle_backtest.py`
- `_load_sell_rules_from_json` 解析 lowVol 档（default + 可选 by_state）
- `sell_rule_for(period_key, state=None, tier="standard")`：tier 取 lowVol 档
- `vol20_at(snaps, asof)`：买入日前 20 个日收益标准差（%）
- `sell_rule_auto(period_key, state, snaps, asof)`：资产双轨入口（回放路径统一调用）
- `run_period(..., tier_auto=True)` / CLI `--tier`
- `simulate_trade` 持到期若超出数据末端 → 最后一根实际交易日了结（reason 标"数据末端"），
  避免长持单在窗口尾部被整笔丢弃（原实现直接 return None）。

## 2. 效果验证（回放对照，单笔口径）

| 窗口（行情） | baseline | 分档(人工 2.8/250/无tp/-15) | 分档(拟合 θ* 3.4/300/无tp/-20) |
|---|---|---|---|
| R1R2 2023-26（牛） | 69.6% / +10.00% / PF3.95 | 72.3% / +20.84% / PF6.46 | — |
| M 2019-23（牛熊混合） | 69.2% / +12.74% / PF4.46 | 67.5% / +18.15% / PF5.03 | — |
| H 2015-18（熊） | 65.4% / +11.68% / PF3.53 | 63.5% / +17.06% / PF4.08 | — |
| 引擎窗口 2025-08~2026-02 | 77.5% / +9.95% | 81.2% / +28.10% | 83.7% / **+32.68%** |

结论：分档在所有行情段把每笔期望收益提高 5~22pp、盈亏因子大幅改善；牛市段胜率反升。

> 注意：上述为「每笔等额本金」口径。真实账户为多仓并发（产品 maxHoldings≈5），长持
> 300d 会占用仓位、减少轮动机会，**落地前需用多仓并发净值模型复核**（§5 未决项）。

## 3. 「已知结果拟合」原型验证（todo2）

思想：历史回溯里每笔信号都有完整未来路径（= 已知结果）。不再人工拍参，而是把
lowVol 档参数 (vol_max, maxHold, tp, sl) 当自由变量，网格搜索使整体组合（standard 现状
+ lowVol 分档）平均单笔收益最大化；**拟合在早期窗口选参 → 更新窗口样本外验证**。

工具：`AutoQuant/_fit_tier_proto.py`（离线 O(1) 模拟 + memo，1051 笔 × 120 组合 ≈ 6s）

结果（全部网格收敛到同一最优族，非单窗口过拟合）：

| 拟合池 | 样本内 θ* | 样本外评估（vs baseline / vs 人工） |
|---|---|---|
| M（2019-23） | vol<3.0/250/无tp/-18 | R1: +7.27→+19.35%（人工17.73）；R2: +11.99→+24.97%（人工23.11） |
| H（2015-18） | vol<3.0/250/无tp/-18 | M/R1/R2 同上显著（θ* 一致） |
| 扩边界后 M | vol<3.8/300/无tp/-22（边界） | R1: +30.67（胜率74.3%）；R2: +28.27（PF10.0） |

要点：
- **跨时代拟合参数高度一致** → 分档信号真实存在于历史结构，不是过拟合噪声。
- 扩边界后最优点到网格边界（3.8/300/-22），但邻域 3.4~3.8×250~300×-18~-22 呈"高原"，
  参数不必精确到个位。为审慎落地取高原中部 **vol<3.4 / 300d / 无tp / -20**（已写回 JSON）。
- 拟合目标当前为「平均收益优先」；如需固定胜率下限或控制止损率，可加约束/多目标。

## 4. 两种正式拟合方案（todo3）

### 方案 A：月度滚动参数重拟合（参数级，推荐先落地）

- 机制：每自然月（复用现有 monthly walk-forward 框架 `smalltools/_walk_forward.py`）在
  "本月为止的全部已实现信号"上网格重拟合 lowVol 档 θ*，把结果写回
  `backtest_params.json → sell_rules.长线.lowVol`（default + 可选 by_state），下月
  APK / AutoQuant exe / smalltools 三端自动生效（现有规则加载已支持 tier）。
- 拟合面：vol_max ∈ [2.4, 2.8, 3.2, 3.6, 4.0]、hold ∈ [180, 250, 300]、
  tp ∈ {0, 50}、sl ∈ [-12, -15, -18, -22]（可用上界剔除 + 坐标下降提速）。
- 目标：avg 为主；可加 soft 约束（如 lowVol 子集胜率 ≥ baseline、止损率上限 30%）。
- 优点：① 结构兼容（sell_rules 已是单一事实源，三端共享）；② 已有确定性模拟与 memo，
  月拟合秒级；③ 有严格的滚动样本外验证流程。缺点：规则形式仍受固定参数结构约束
  （无法表达"状态×波动率"之外更细的非线性）。

### 方案 B：卖出时刻结构学习（结构级，探索性）

- 机制：不预设 maxHold/tp/sl 参数结构。把每笔信号从买入日起的每个交易日建成样本：
  特征 = 当前浮盈、持有天数、vol20、bias250/动量、大盘状态、距离新高/均线等；
  标签 = "今日卖出收益" vs "继续持有到未来 T 日（T=20/40/60…）的期望收益增量"。
  用树模型/逻辑回归学停止条件 f(features) → 输出"该不该继续拿"的分段决策，
  可自然发现"低波动 + 浮盈加速 + 大盘震荡时继续持有；高波动 + 冲高回落则了结"之类结构。
- 输出形态：可选两种落点——(a) 训练出规则树后编译成参数规则（保持 sell_rules 结构，
  拟合 by_state 细分）; (b) 直接在引擎里按特征打分决定卖出（改动大、需 eval 层支持）。
- 优点：可能发现固定参数网格发现不了的非线性/交互规律；缺点：过拟合风险高、
  特征有效性待检验、需要严格 walk-forward + 防泄漏设计、工程落地成本高。

### 推荐路线

1. 先落地方案 A（增益已验证、成本低、结构兼容）→ 随月度窗口持续自校准。
2. 用方案 B 做离线研究：先用同一批回溯验证"树模型停止条件 vs 固定参数"样本外增益，
   有显著增益再谈落地。

## 5. 2026-09-05 增补：方案A/B 全部落地 + 修正机制实验结论

### 5.1 方案A / 方案B 都实现并样本外验证

- **方案A（单一 lowVol 档参数拟合）**：`AutoQuant/_fit_tier_proto.py`，已写回
  `backtest_params.json`（vol<3.4 / 300d / 无tp / -20）。
- **方案B（结构化规则矩阵：state × 波动档 每格独立拟合）**：`AutoQuant/_fit_tier_matrix.py`
  （可编译回 `sell_rules[长线].by_state[state]` 结构）。M 训练 → R1/R2 样本外：

| 池 | baseline | 方案A | 方案B 矩阵 |
|---|---|---|---|
| R1（2023-24） | +7.27% / PF2.66 | +26.33% / PF6.04 | **+33.64%** / PF7.03 |
| R2（2025-26） | +11.99% / PF5.50 | +26.45% / PF9.56 | **+32.22%** / PF10.91 |

H（2015-18 真熊）训练的矩阵在 M/R2 样本外同样有效（M +40.07%/PF8.41）。矩阵格子
几乎一致收敛到 300d/无tp/sl-18（含高波档 hv）——说明增量主要来自"高波档也放宽到
300d/sl-18"，而非 state×vol 交互。因此：

- **保守落地**维持方案A（lv<3.4 档）；**激进档**（全量 300d/sl-18）可做成配置预案，
  但必须先过 §5.4 的多仓净值复核（单笔等本金口径不含 300d 持仓的机会成本）。

### 5.2 两种回溯的关系（第3问）——用已知拟合修正非已知拟合：可行且已验证

`AutoQuant/_tier_wf_shrink.py` 递归 walk-forward 实验（无泄漏）结果：
- 阶段1（H+M 训练→R1 样本外）+33.64%，阶段2（H+M+R1 训练→R2 样本外）+32.22%；
- 两阶段矩阵漂移 **0/9 格**；与"全样本已知拟合（含未来）"矩阵对比漂移也是 **0/9 格**。

结论：该规则是历史稳态结构，**前视信息影响极小**。修正机制落地建议：
每月滚动重拟合时**以全样本稳态矩阵 θ* 为初始化中心**，只在其小邻域内搜索微调
（先验收缩），即可同时获得"月度数据自校准"与"抑制月度小样本噪声"。风险提示：
该结论基于 2015-2026 这段采样；若未来发生 regime 剧变，漂移检测（0/9 指标）会报警，
届时需放开邻域重新全局搜索。

### 5.3 做T机会扫描（PC 侧工具，第6问）

`AutoQuant/autoquant/t_trade_scan.py`：对实仓/三大周期持仓逐只输出低吸/高抛区间、
SAR 轨、RSI/MACD 状态、ATR 弹性、换手/量比档位与操作建议；自动剔除末端量能断崖的
不完整交易日（避免"均值近似崩溃"类误判）。数据源统一 `data/market_data.db`。
区间算法与 APK `TTradeEngine.generateSignals` 同构（近 5~7 日高低带 + 均线钳制支撑压力）。
