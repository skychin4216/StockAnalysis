均線金叉策略 ma_golden_cross TREND
當短期均線（如 MA5）上穿長期均線（如 MA10），形成「金叉」信號，代表短期動能轉強，趨勢由空轉多。 本策略綜合考量均線斜率、成交量配合程度及距離壓力位的空間，過濾假突破，提升勝率。

市場環境分析器

MarketAnalyzer

實時評估大盤環境狀態（BULLISH / NEUTRAL / BEARISH），綜合考量大盤均線排列、成交量趨勢、市場情緒指標、板塊漲跌比等因素，為下游決策提供市場背景上下文。

利潤質量分析器

ProfitQualityAnalyzer

對已持有倉位的利潤進行質量分級（A+ / A / B+ / B / C），分析利潤來源（基本面驅動 vs 投機推動）、利潤穩定性及可持續性，指導止盈策略選擇。

持倉水位閥門

PositionWaterValve

動態管理總持倉水位，根據市場環境和利潤質量調整持倉比例上限。牛市高水位（80%）、中性中水位（50%）、熊市低水位（20%），並根據風險事件觸發緊急排水。

V2DecisionMatrix
