说明：CrossTabBus 作为跨 Tab 通信中枢，实现各 Fragment 之间的解耦通信。
  • 发送方：StockDetailFragment（持仓操作）、StrategyFragment（策略选股）、AiSelectedStocksFragment（AI推荐）、ChatTabFragment（AI对话）、SectorTabFragment（板块选股）等均可向总线发送事件。
  • 接收方：WatchlistUnifiedFragment 刷新自选、StockTabFragment 跳转详情、CandidatePoolFragment 更新候选、AgentTabFragment 同步 Agent 状态、ConversationListFragment 更新对话历史、MarketHotFragment 联动热门板块。
  • 优势：通过总线解耦，Tab 之间无需直接持有引用，降低耦合度，便于扩展新的事件类型与接收方。
