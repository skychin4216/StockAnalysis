分层说明：

· UI 层（ui/）：由 MainActivity 通过底部导航承载 5 个 Tab，并包含 StockDetailFragment 与 ChatTabFragment，负责交互与展示。

· 业务逻辑层：意图处理链 IntentProcessorChain、策略引擎 StrategyEngine、Agent 运行器 UnifiedAgentRunner、模拟交易 SimulationTradeEngine 与 AI 编排 AiOrchestrator，是核心调度中枢。

· 数据层（stock/）：查询引擎 StockQueryEngine 经多源仓储 MultiSourceStockRepository 协调 Room 持久化与智能缓存。

· 外部 API：东方财富 / 腾讯 / 新浪 / AKShare 提供行情数据，OpenAiCompatibleProvider 提供大模型能力。

链路说明：

1. 用户操作经 UI Fragment 进入 IntentProcessorChain，完成意图识别与分发。

2. StockQueryEngine 调用 MultiSourceStockRepository，由其判断是否命中智能缓存或 Room 本地库。

3. 未命中时通过数据源适配器调用外部 API（东方财富 / 腾讯 / 新浪 / AKShare），返回数据经规整后回写缓存并向上返回 UI。

· 关联业务流：策略执行（StrategyEngine → 11 种 Strategy → StockScreener → AIPredictionEngine → AI Provider）、AI 深度分析（UnifiedAgentRunner → AgentPipelineOrchestrator → 6 个 Agent → PipelineResult）、量化交易（SimulationTradeEngine → 9 步精选 → generateBuyOrders → Room DB）均复用上述数据层与 AI 编排能力。

依赖说明：

· ui/ 是最上层消费者，依赖业务与数据多包（stock / strategy / agent / ai / conversation / memory / config）。

· strategy/ 与 agent/ 存在协作：策略在选股与预测时调用 AI 与 Agent 管道，Agent 管道也依赖 AI 与数据层。

· ai/ 通过 OpenAiCompatibleProvider（OkHttp，支持流式 / 非流式）对接大模型，包含 AiProviderPool 健康探测与 BackgroundPredictor 后台预测。

· config/（功能开关）与 storage/（备份）处于基础层；conversation、memory 依赖 storage 持久化；news/ 依赖 stock；skill/ 依赖 agent 与 ai。
