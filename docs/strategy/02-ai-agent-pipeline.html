核心入口：UnifiedAgentRunner.run(context, stockCode, stockName, mode, sector) 是所有分析的统一入口，返回结构一致的 Result 对象，底层差异对外透明。

三种模式对比：

  • MODE_QUICK（快速分析）：3 个 Agent 并行执行（StockAnalysisAgent + RiskManagementAgent + MarketAnalyzer），耗时短，适合快速浏览。
  • MODE_PIPELINE（深度分析）：AgentPipelineOrchestrator 执行 6 步串行管道，每步携带前序输出，深度递进，适合决策前研判。
  • MODE_V2（专家分析）：V2AgentRunner 并行采集市场环境、利润质量、AI 分析三路数据，经 V2DecisionMatrix 融合输出操作指令。

未知 mode 自动回退到 Quick 模式。

串行传参规则：每一步的 LLM prompt 中注入前面所有步骤的分析摘要（越靠后摘要越精简：前 2 步 600 字、中 2 步 400 字、后 2 步 250 字），确保后续 Agent 基于前序完整上下文决策。

max_tokens 分层策略：前期分析步骤（Step 1-3）配额 4096，中期深度步骤（Step 4-5）配额 6144，最终交易方案（Step 6）配额 8192，避免截断同时防止过长回应。

Agent F（DataFeeder）：作为数据底座与主线并行启动，通过 LLM 实时联网采集催化事件、外资评级、供需格局三类情报，5 分钟缓存避免重复采集，注入到每步 prompt 的【最新产业情报】区块。

PipelineResult：核心字段 stepAnalyses: Map<Int, String> 保存各步原始 Markdown 分析文本，intelligence: DataFeederResult 保存 Agent F 采集的情报，供 UI 展示和回溯。

三层架构：V2 决策系统采用「顶层战略 → 中层战术 → 底层执行」三层融合架构。

  • 顶层战略（市场环境）：MarketAnalyzer 判断大盘方向（BULLISH / OSCILLATION / BEARISH），PositionWaterValve 根据趋势方向和强度计算仓位上限（10%-100%）。
  • 中层战术（利润质量）：ProfitQualityAnalyzer 通过「利润质量剪刀差」测试（净利润 vs 扣非净利润差距 + 经营现金流覆盖率），区分内生性增长与一次性浮盈，识别市盈率陷阱。
  • 底层执行（决策矩阵）：V2DecisionMatrix 将环境 × 利润质量 × 估值三者融合，输出 FinalDecision（含操作指令、建议仓位、做T建议、止损规则、风险提示）。

关键防陷阱逻辑：震荡市 + 一次性浮盈 = 最危险组合（静态 PE 极低诱人但利润不可持续），决策矩阵强制输出「短线反抽」而非「格局持有」。

分层架构总览：系统从底向上分为 6 层，每层职责清晰、单向依赖。

  • 数据层：StockDataFacade（实时行情）、QuarterlyComparisonProvider（季度环比）、FactorDataProvider（估值因子）、StockScreener（选股筛选），为上层提供原始数据。
  • Agent 层：7 个独立 Agent，各司其职。DataFeeder（Agent F）作为数据底座为管道注入情报。
  • V2 决策层：ProfitQualityAnalyzer（利润质量）+ PositionWaterValve（仓位水阀）+ V2DecisionMatrix（决策矩阵），三层融合输出操作指令。
  • 管道编排层：AgentPipelineOrchestrator 编排 6 步串行管道，StructuredOutputParser 解析结构化输出，PipelineProgressView 展示进度。
  • 运行入口层：UnifiedAgentRunner 统一三种模式，V2AgentRunner 专责 V2 模式。
  • 路由层：6 个 Router 根据 FeatureFlagManager 配置在 Agent 实现与 Legacy 实现间路由。

关键复用：StockAnalysisAgent 被 Quick / Pipeline / V2 三种模式共用；MarketAnalyzer 被 Quick / V2 模式共用；StockDataFacade 被多数 Agent 依赖，是数据层的核心枢纽。
