## 一、大盘趋势判断（AMarketAnalysisEngine · 六维分析）

> 代码：`strategy/market/AMarketAnalysisEngine.kt`（指数代码 sh000001，60 日窗口）

| 维度 | 检测项 | 输出 |
|------|--------|------|
| 1. 趋势与形态 | 三日不新低（近3日 low ≥ 前3日最低low）/ 均线粘合 / 逃顶信号 | `isBottomConfirmed` / `isTrendUp` / `isTopDanger` |
| 2. 量能与资金 | 放量 / 缩量 / 平量 | `volumeStatus` |
| 3. 市场情绪与波动 | 全市场涨跌比 → 沸腾 / 温和 / 冰点 | `marketTemp` |
| 4. 权重股贡献度 | 大盘股 vs 小盘股涨幅差（黄白线偏离替代） | 预留 |
| 5. 宏观事件日历 | CPI / PPI 等 | 预留接口 |
| 6. 大盘状态机 | 综合决策 | `suggestedPeriod` + `suggestedPositionPct` |

### 状态机决策（decidePeriod）

- 底部确认 + 趋势向上 → **中线/长线**，高仓位（如 70%）
- 冰点情绪（涨跌比极低）+ 底部 → **短线抄底**，中仓位
- 顶部危险 / 趋势向下 → **超短快进快出** 或 空仓，低仓位
- 连涨/连跌预警：`consecutiveUpDays` / `consecutiveDownDays` → `streakRiskLevel`（LOW/MEDIUM/HIGH/EXTREME）
- 量价背离（涨但缩量）→ 风险提示

### MarketMaUnifiedNode（大盘均线统一检查）

- `threshold`：超短 0.015，其他周期 0.02（均线发散容忍度）
- `checkMode`：full（大盘均线粘合/多头排列才放行）
- 大盘弱 → 各节点自动收紧（effectiveLookback/effectiveConvergence 动态调整）

## 二、三天不新低（三日不创新低 · 底部确认）

> 代码：`StockCheckPipeline` 第 13 项 + `AMarketAnalysisEngine.checkBottomConfirmed` + `base_position_guard`

**规则**：近 3 个交易日最低价均 ≥ 前 3 天最低价 → 底部确认加分。

```kotlin
val last3 = snaps.takeLast(3)
val prevLow = snaps[snaps.size - 4].low
val threeDayNoNewLow = last3.all { it.low >= prevLow }
```

**使用位置**：
- **六项严选**第 2 项（`requireThreeDayConfirm=true` 时计入）
- **打底仓守门**：三天不新低 + 均线粘合向上，才允许打底仓
- **大盘**：指数三日不新低 → `isBottomConfirmed`
- **腾龙换鸟**：中线空头排列 OR 创新低即换股；长线空头排列 AND 创新低才换股（更保守）

### ⚠️ v3 适配：大盘向上(BULLISH)时不强制"三日不新低"

上升趋势中均线发散、股价不断上行，`三日不新低`天然不满足，会**错误过滤强势股**（
此前 8/11-8/13 牛市回测 111/111 全未过，导致超短/短无选股）。

修正：`StockCheckPipeline` 在 `MarketRegime.BULLISH` 时自动关闭该检查（`requireThreeDayNow =
requireThreeDayConfirm && regime != BULLISH`），**仅在大盘下跌/震荡(BEARISH/NEUTRAL)时强制**。
这正是"超短/短跟随趋势，中/长线底部埋伏"的核心差异所在。

## 三、大A祖训（AncestralRulesNode · 五条量化规则）

> 代码：`strategy/topology/nodes/AncestralRulesNode.kt`（60 日回看窗口）

| # | 祖训 | 量化条件 | 各周期加减分 |
|---|------|---------|-------------|
| 1 | **高开要跑** | 高开>2% 且收阴 | 超短 **-15** / 短 -10 / 中 -5 / 长 -3 |
| 2 | **买无人问津时** | 换手<1% + 60日低位15%以内 | 超短 +3 / 短 +5 / 中 **+12** / 长 **+15** |
| 3 | **卖人声鼎沸时** | 换手>8% + 60日高位5% + 量价背离 | 超短 **-12** / 短 **-15** / 中 -10 / 长 -8 |
| 4 | **低位利空=利好** | 60日低位20% + 跌>3% + 下影线 | 超短 +5 / 短 +8 / 中 +15 / 长 **+20** |
| 5 | **高位利好=利空** | 60日高位5% + 涨>3% + 墓碑线 | 超短 **-10** / 短 **-12** / 中 **-15** / 长 **-15** |

> 解读：短线重情绪（高开/鼎沸），中长线重低位埋伏（无人问津/利空），祖训是**全周期通用经验层**。

## 四、K线图分析

### 4.1 盘口K线分析（intraday_analysis）

- 交易时段获取 **5 分钟 K 线**（≥5 根）
- 评估日内趋势与买卖点（冰点/沸点）
- 超短/短线 Pipeline 专有，为 T+1 / 做T 提供日内择时

### 4.2 形态侦测（candle_pattern · CandlePatternDetector）

经典 K 线形态识别，输出 `PatternMatch(patternName, direction)`：
- **看多形态**：锤子线 / 早晨之星 / 看涨吞没 等 → 加分
- **看空形态**：墓碑线 / 黄昏之星 / 看跌吞没 等 → 减分

用于：
- 做T 信号置信度（±15）
- 选股 Pipeline（`candle_pattern` 节点）

### 4.3 趋势方向（analyzeTrendDirection）

综合均线排列 + RSI + K线形态 → "准备上升/上升中/下跌中/准备下跌/盘整"，用于做T 与持仓风控。

## 五、六项严选（StockCheckPipeline · 均线多头粘合框架）

> 代码：`strategy/topology/pipelines/StockCheckPipeline.kt`

| # | 检查项 | 说明 |
|---|--------|------|
| 1 | MA 收敛向上 | 5/10/20/60 均线粘合（convergenceThreshold 按周期 3.0/3.0/2.5/2.0） |
| 2 | 三日不创新低 | 近 3 日 low ≥ 前 3 日最低 low（**仅 BEARISH/NEUTRAL 强制**，BULLISH 自动关闭） |
| 3 | 历史低位 25% | close 在 60 日区间下 25% |
| 4 | PE 低估 | 估值过滤 |
| 5 | 周期活跃 | 成交量/换手处于周期活跃区间 |
| 6 | 冰点买入 | 价格处于日内/区间冰点 |

**通过门槛（minPassCount）**：超短 8 项 / 短线 7 项 / 中线 7 项 / 长线 8 项（含周期专属项）。

### ⚠️ v3 核心变更：超短/短线在牛市切换到"趋势跟随"模式

`StockCheckPipeline` 新增 `AnalysisMode.TREND_FOLLOW`。`ultraShortParams`/`shortTermParams`
已配置为趋势跟随，不再走均线粘合（`CONVERGENCE`）。**中/长线仍用均线粘合**。

**趋势跟随 6 项检查**（过 ≥5 且当日须上涨，剔除 ST）：
1. 多头排列  MA5>MA10>MA20[>MA60]（趋势向上核心）
2. 贴近新高  收盘距 20 日高点回撤 < 8%（强势不追高）
3. 放量      当日量 / 5 日均量 ≥ 1.2（超短）/ 1.0（短）
4. 当日上涨  真实涨幅 > 0（突破强度）
5. MA20 上行 MA20 > 前日 MA20（趋势持续）
6. 站上5日线 收盘 > MA5（强势确认）

> 为什么：牛市均线发散，粘合/三日不新低天然不满足，会错误过滤强势股。
> 趋势跟随捕捉"多头排列 + 贴近新高 + 放量上涨"的强势突破股，已实测 8/11-8/13 每日选出 7-8 只。

### 周期专属严选参数

| 周期 | 模式 | 粘合阈值 | 粘合天数 | 放量倍率 | 回撤 | 要求 |
|------|------|---------|---------|---------|------|------|
| 超短 | **趋势跟随** | — | — | 1.2x | 贴新高<8% | 6项≥5 + 当日上涨 |
| 短线 | **趋势跟随** | — | — | 1.0x | 贴新高<8% | 6项≥5 + 当日上涨 |
| 中线 | 均线粘合 | 2.5 | 15 天 | 温和 1.2~1.8x | ≥30% | MA60 向上 + 站上所有均线 |
| 长线 | 均线粘合 | 2.0 | 30 天 | 地量 | ≥30% | MA60/MA250 同步上翘 + 站稳年线 |

## 七、其他经验规则（避免遗漏）

### 7.1 板块轮动惩罚（rotation_penalty）

板块涨幅超阈值天数越多，每超一天罚 10 分（追高惩罚，`thresholdDays=3`）。

### 7.2 新闻拦截（news_guard）

- 利空新闻（impact≥75 / sentiment<0）拦截
- 新闻力度近 3 日评估（news_strength）

### 7.3 主力资金过滤（smart_money_filter）

- 超短 minScore=30（V 型票天然低分）
- 其他周期 minScore=55

### 7.4 防守高息（defensive_dividend）

熊市/震荡启动：银行/电力/高速公路等防御板块，低 PB（≤1.5/1.2）+ 低负债 + 高股息代理。

### 7.5 打底仓守门（base_position_guard）

「长线看势，中线看价，短线看量，超短看情绪；逃顶要快，抄底要慢」

### 7.6 腾龙换鸟（swap_weak）

- 卖出最弱持仓（空头排列/创新低/回撤超限）
- 买入更强股票；长线需双重确认（空头排列 AND 创新低）才换股
- 换股后自动诊断分析（HoldingDiagnosticAnalyzer）

### 7.7 大A 短线口诀

- 「要热点热点热点」—— 短线热度优先
- 「买无人问津时，卖人声鼎沸时」—— 逆向思维
- 「逃顶要快，抄底要慢」—— 顶快底慢

## 八、四周期 usercase + 自动持仓引擎（v3 新增）

> 代码：`strategy/trade/AutoTradePortfolioEngine.kt`

### 8.1 四周期 usecase 分工

| 周期 | 选股模式 | 大盘 | 持仓纪律 | 做T/反T |
|------|---------|------|---------|--------|
| 超短 | 趋势跟随 | 牛市 | 快进快出，止盈/止损快（止损 -2%） | 有大利润可做T/反T |
| 短   | 趋势跟随 | 牛市 | 跟随趋势，波段持有（止损 -5%） | 有大利润可做T/反T |
| 中   | 均线粘合 | 底部/震荡 | **底仓不动，做T降成本为主**（止损 -8%） | 主做T，振幅≥2% |
| 长   | 均线粘合 | 底部 | **坚持持有**（止损 -10%） | 极少做T，仅极端波动(振幅≥4%) |

### 8.2 自动交易持仓引擎（100 万资金）

`AutoTradePortfolioEngine` 统一管理跨周期持仓：

- **总投资 100 万**，单只建仓 ≤ 总资金 20%（约 20 万），保留现金 ≥ 10%
- **统一持仓 ≤ 5 只**（选股 ≤ 5 只，一次建仓 ≤ 3 只）
- **做T/反T 自动执行**：每周期若符合（日内振幅达门槛 + 日内低位/高位），自动调用
  `TTradeEngine` 执行 T_BUY（低吸）/RT_SELL（高抛），**手数 = 底仓 × 40% 自动决策**（整手）
- **腾笼换鸟守则**：新票强度 ≤ 最弱持仓 + 15 分时**不换**（保留强势持仓）
- **止盈/止损**：按周期差异化止损线（超短 -2%/短 -5%/中 -8%/长 -10%），多头排列破坏且有利润则止盈

### 8.3 资金分配示例（8/11-8/13 实测）

- 单只建仓约 20%（华新建材 20万 / 阳光电源 19.2万 / 锦浪科技 19.7万）
- 做T数量 = 底仓 40%（如 8200 股底仓 → 做T 3200 股）
- 保留现金 ≥ 10%，超短止损 -2% 触发即清仓回收资金
- 新候选强度不足时跳过（不腾笼换鸟），避免频繁换股损耗

### 8.4b 回测（7/1 ~ 8/13）与逻辑互斥修正

> 工具：`smalltools/_profit_backtest.py`（选股+盈利）、`_profit_analyze.py`（信号分布+基准）、`_optimize_short.py`（短线参数拟合）

**① 逻辑互斥修正（超短/短线不进入中/长线）**

超短/短线在牛市用**趋势跟随**（放量突破、贴近新高、回撤<8%、当日上涨），而中/长线用**均线粘合**（地量、
均线粘合、回撤≥30%/40%、站稳年线）。两者本质互斥：一只贴近新高、放量突破的强势股不可能同时是"低位地量埋伏"标的。

`UnifiedStockClassifier.classifyAll` 已增加强制排除：**一旦命中超短或短线 → 剔除同股的中线/长线**，
避免同一只强势股被同时归入矛盾周期。

**② 7/1~8/13 回测结论（111 只核心龙头，无未来函数：信号次日开盘买入）**

基准（同期买入全部核心股等权）：1天 -0.56% / 4天 -1.28% / 10天 -3.89% / 20天 -8.12% —— **该阶段为回调/下跌市**。

| 周期 | 模式 | 已实现 | 平均收益 | 胜率 | 结论 |
|------|------|--------|---------|------|------|
| 超短 | 趋势跟随 | 12 | -0.12% | 41.7% | 略跑赢基准(-0.56%)，止损保护有效 |
| 短   | 趋势跟随 | 11 | -3.92% | 9.1% | **明显跑输基准(-1.28%)，策略失效** |
| 中   | 均线粘合 | 0 | — | — | **32 天 0 信号** |
| 长   | 均线粘合 | 0 | — | — | **32 天 0 信号** |

**③ 发现的前后矛盾 / 隐患**

1. **中/长线 0 信号**：核心股票池在 7/1~8/13 均处于均线发散向下的回调状态，CONVERGENCE（粘合+地量+回撤≥30/40%）
   苛刻条件无一命中 → 中/长线在此阶段完全无法建仓。阈值/池子需优化。
2. **短线在牛市信号后随即回调**：7/1、8/12 两天 tripleVote=BULLISH 触发趋势跟随（11 只），但次日市场转弱，
   全部止损。**趋势跟随缺少"大盘转弱即离场/暂停新买"保护**。
3. **信号高度聚集**：趋势跟随在单日（7/1、8/12）同时选出 11~25 只，之后长时间无信号 → 需限制单日建仓数量。
4. **回测工具与 Kotlin 逻辑不一致（旧工具）**：`backtest_guangmo.py`/`_multiday_backtest.py` 仅用 CONVERGENCE
   回测所有周期，未实现 TREND_FOLLOW，导致超短/短线在牛市被错误地测得"0 选股"。`_profit_backtest.py` 已按
   真实逻辑（牛市超短/短=趋势跟随，其余=粘合）修正。

**④ 短线参数拟合（`_optimize_short.py`）**

牛市趋势跟随信号仅 11 笔（样本过少）。在持有 2/3/4/5 天、止盈 +5~15%、止损 -3~-5% 的网格下**全部为负收益**
（单笔 -0.6%~-4%），加"破 MA5 移动止盈"仍为负。**结论：该阶段负收益是市场环境（牛市信号后转弱）所致，非参数问题**；
任何调参都无法在一个月下跌市中让趋势跟随盈利，需配合"大盘转弱保护"。

### 8.4c 大盘转弱离场保护 + 中线/长线产业主线过滤（v4.1）

针对回测暴露的两个核心隐患（趋势跟随缺"大盘转弱离场"、中/长线无产业逻辑门槛）落地代码：

**① 大盘转弱离场保护（`MarketTrendGuard.kt`）**

7 月份连续四天下跌，本应在**第一个大跌日**收手离场、快速止损，等趋势恢复后再入场。为此新增多指数风险状态机：

- **多指数分板块归属**（解决科创板严重偏离上证）：
  - 科创板 `sh688*` → 科创50 `sh000688`
  - 创业板 `sz300*/301*` → 创业板指 `sz399006`
  - 沪深主板 → 上证指数 `sh000001`
- **转弱触发（RISK_ON→RISK_OFF，命中任一即离场）**：
  - 单日暴跌 ≤ -3%（暴力下杀）；
  - 单日下跌 ≤ -2% 且跌破 MA5（趋势拐头第一天）；
  - 连续 2 日下跌且累计跌幅 ≤ -2.5%（如 7 月连续下跌在第 2 天即触发）；
  - 收盘跌破 MA10 且 MA5 掉头向下。
- **恢复入场（RISK_OFF→RISK_ON）**：连续 2 日收盘站上各自 MA5 且最新 MA5>MA10（均线修复）。
- 状态持久化到 SharedPreferences，跨重启保持，避免重复入场/漏退场。

接入点：
- `UnifiedStockClassifier.classifyAll`：所属指数 RISK_OFF 时，**禁止趋势跟随（超短/短）选入**（中线/长线不受限，因为看产业逻辑+低位埋伏）；
- `AutoTradePortfolioEngine.autoOpen`：趋势跟随周期所属指数转弱时**暂停新建仓**；
- `AutoTradePortfolioEngine.autoScanSell`：趋势跟随持仓所属指数转弱时**强制离场**（提前止损，不等个股跌到止损线）。

**② 中线/长线产业主线过滤（`IndustryThemeClassifier.kt`）**

中线/长线看**产业逻辑**而非高弹性动量，所以中/长线只买入属于受关注产业主线的股票：

| 主题 | 板块 |
|------|------|
| AI算力硬件 | AI算力、GPU服务器、光通信/光模块/CPO、铜缆高速连接 |
| 存储 | 存储芯片、HBM、存储模组 |
| PCB | 服务器PCB、HDI、IC载板、覆铜板、电子布、铜箔 |
| 稀有金属 | 钨钼铌钒钛、稀土、铜、铝、锂等有色/稀缺小金属 |
| 稀有气体 | 氦气、稀有气体（电子特气） |
| 半导体国产替代 | 半导体设备、材料、光刻胶、设计、封测、功率 |
| 战争资源 | 石油、黄金（地缘冲突时升温） |

- 数据源：`LeaderStockPool`（用户/Agent 可动态增删板块）为主 + 名称/主营关键词匹配。
- 接入：`classifyAll` 中，**中线/长线** Pipeline 技术面通过后，若未命中任何已知产业主线 → 剔除；命中则在结果标注 `industryTheme`，并在选股 UI / AI精选 reason 中展示。

**③ 逻辑互斥**：延续 8.4b 的强制排除——一旦命中超短或短线 → 剔除同股的中线/长线，避免同一只股票同时走两个矛盾通道。

### 8.4d 宏观环境动态分析 Pipeline（v4.2）

在 8.4c 的「多指数 + 产业主线」基础上，进一步落地「**根据大环境动态分析规划**」：不仅看 A 股自身，还综合**全球市场、大宗商品、宏观事件**，动态调整板块偏好与仓位纪律，而不是机械套用固定参数。

新增 `strategy/trade/macro/` 四个模块：

**① 全球市场 + 大宗商品采集（`MacroMarketDataFetcher.kt`）**

复用既有 `EastMoneyHotSectorSource.globalIndices`（美股纳斯达克/标普/道琼斯、韩股 KOSPI、恒生等），并对大宗/利率新增拉取：

| key | 资产 | 用途 |
|-----|------|------|
| `OIL_WTI`/`OIL_BRENT` | 原油 | 判断油价趋势 → 化工联动 |
| `GOLD` | 黄金 | 避险/抗通胀 |
| `US10Y` | 美债10Y | 全球利率 |
| `USD_INDEX` | 美元指数 | 流动性/新兴市场压力 |
| `KR_KOSPI` | 韩国KOSPI | 存储/半导体产业链次日联动 |

**② 指数偏离监测（`IndexDeviationMonitor.kt`）**

解决「科创板/创业板严重偏离上证」时的**均值回归回调风险**：计算 `RS = 板块指数/上证`，看当前 RS 相对 20 日均值的偏离度 `(RS-mean)/mean`，叠加短期斜率加速 + 连涨天数，给出回调风险等级：

- `LOW` 正常 → 趋势跟随继续；
- `MEDIUM` 偏离扩大 → 留意资金退潮；
- `HIGH` 严重偏离 → **趋势跟随暂停追高**；
- `EXTREME` 极端偏离 → **强制减仓/规避**该板块高位趋势股。

**③ 事件场景引擎（`EventScenarioEngine.kt`）**

维护「事件状态机」（`warPhase` + `policyPhase`），对每个产业主题给出净偏好分 `bias ∈ [-100,+100]`：

- **战争前/中/后期**：战前避险+资源先行 → 爆发时能源/黄金/军工急涨、成长被抽血 → 僵持时化工接力（油价高位传导）→ 战后风险偏好修复、科技回补；
- **油价→化工联动（动态）**：油价上行 → 化工（油头化工/石化）+20；油价下行 → 化工成本支撑减弱 -10；
- **美国 CPI/加息**：鹰派加息 → 压制成长估值（存储/PCB/半导体 -10~-15），利好抗通胀资源（+15）；
- **美股/韩股外部联动**：隔夜纳斯达克走弱 → A 股 AI/半导体承压；韩股走弱 → 存储/半导体联动承压。

**④ 主入口聚合（`MacroEnvironmentAnalyzer.kt`）**

并行采集以上 4 类信号，输出统一 `MacroSnapshot`：
- **综合风险分** `overallRisk(0-100)` → `SAFE/CAUTION/DANGER/CRITICAL`；
- **板块偏好矩阵** `sectorBias`（产业主题→净偏好分，已叠加指数偏离回调惩罚）；
- **指数专属信号**（转弱 + 偏离）；
- 结果持久化（10 分钟内一致消费）。

**接入与效果：**
- `UnifiedStockClassifier.classifyAll`：
  - 趋势跟随（超短/短）所在板块指数**偏离 HIGH/EXTREME** 时**暂停追高**（叠加 8.4c 的大盘转弱）；
  - 中线/长线若落于当前**宏观逆风产业**（偏好 ≤ -15，如加息压制存储/PCB、战争升级抽血科技）→ **剔除**，实现「顺风重仓、逆风规避」。
- `AutoTradePortfolioEngine`：
  - `autoOpen`：趋势跟随建仓前，除大盘转弱外，**板块偏离回调**也暂停追高；
  - `autoScanSell`：趋势跟随持仓所在板块**偏离回调**时**提前离场**（止盈/规避补跌）。

> 注：事件状态（战争阶段/政策阶段）默认由 Agent/用户根据新闻通过 `EventScenarioEngine.updateEventState()` 写入；亦可未来接入新闻因子自动判定。油价/美股/韩股等行情走东方财富统一接口自动采集。

### 8.5 预选 Tab（提前选股）

新增**预选** Tab（`PreselectionFragment`），UI 与「选股」页**完全一致**，仅交易规则不同，作为**提前选股**思路：

- **买入（预选建仓）**：仅在**非交易时间**可执行——非交易时段锁定的优选标的，供下一交易日开盘参考。
- **卖出**：仅在**交易时间**可执行。

顶部状态栏会实时显示当前是否为交易时间（🟢交易中/⚫非交易），交易时间内预选建仓按钮被禁用并提示改到「选股/实仓」执行。
预选扫描结果写入 `ai_selected_stock`（source=`preselection`），与选股（`unified`）区分，便于追溯来源。
