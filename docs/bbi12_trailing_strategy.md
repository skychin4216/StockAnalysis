## 1. 策略一句话

**BBI12 谷底拐点确认买入；峰顶拐点确认 或 自持仓最高价回撤 ≥8% 止盈（先到先卖）；稳健模式额外要求买入时 Δ5ER > -0.05。**

## 2. 指标定义（全部无未来函数）

| 指标 | 定义 | 参数 |
|---|---|---|
| BBI | (MA3+MA6+MA12+MA24)/4 | — |
| BBI12 | SMA(BBI, 12) | 12 |
| 谷底拐点 | BBI12[t-1]≤BBI12[t-2] 且 BBI12[t]>BBI12[t-1]，t 根收盘确认（信号根=确认根 t） | — |
| 峰顶拐点 | BBI12[t-1]≥BBI12[t-2] 且 BBI12[t]<BBI12[t-1]，同上确认 | — |
| ER（Kaufman 效率比） | \|C[t]−C[t−60]\| / Σ\|ΔC\|（近 60 根） | W=60 |
| Δ5ER | ER[t] − ER[t−5] | 步长 5 |
| Δ5ER 金叉 | Δ5ER[t−1]≤0 且 Δ5ER[t]>0 | — |

数据口径：1H K 线（小时线），收盘价触发，手续费 0.13%/边（回测）。

## 3. 双模式规则

### 3.1 进取模式（AGGRESSIVE）
- **买**：BBI12 谷底拐点确认根收盘价买入
- **卖**（持仓中逐根检查，先到先卖）：
  1. BBI12 峰顶拐点确认 → 峰顶卖
  2. (持仓最高价 − 现价)/持仓最高价 ≥ 8% → 止盈卖
- 持仓最高价含当根收盘（先更新高点再判定）

### 3.2 稳健模式（STEADY）
- 同进取，但买入多一道过滤：**拐点确认根 Δ5ER > -0.05 才买**
- Δ5ER ≤ -0.05 的谷底拐点记录为 SKIP 信号（急降中继，放弃）
- 逻辑：ER 正在自由落体说明趋势刚死，此时的拐点大概率是下跌中继而非真底

### 3.3 Δ5ER 金叉预警（两模式共有，仅提示不交易）
- 空仓时最近 3 根内出现 Δ5ER 金叉 → advice =「金叉预警」
- 历史统计：金叉领先谷底拐点平均 6.4 根（中位 6，范围 2~14），金叉价 88% 低于拐点确认价
- **定位是情报信号（提前盯盘），不是买入信号**——金叉假信号率 67%（98 中 66 假）

### 4.3 参数选择依据
- **止盈 8%**：扫描 5/8/10/12/15/20%，8% 是 600176 收益/回撤双优拐点；≥15% 等于不触发，5% 太紧丢利润
- **Δ5ER > -0.05**：600176 上 Δ5ER 急降(<-0.05)的拐点 5 笔亏 4 笔；过滤阈值再严（>-0.01）会误杀 t476/t681 两笔最大盈利（+28%/+62%），收益腰斩
- **稳定性警示**：稳健模式前后半段拆分 = 前半 +0.14% / 后半 -3.15%，有区间依赖性，需持续观察

## 5. 已证伪路径（不要再试）

| 方案 | 结果 | 失败原因 |
|---|---|---|
| ER≥70 横截面闸门 + 0% 跌破止损 | 600176 +214%→-8% | ER 是后视镜：大盈利启动前 ER 必低（t476 ER分位=28，t681=36），闸门精确过滤掉最大的两笔；0% 止损被小时级噪音反复触发 |
| ER 横截面阈值提高到 90/92 | 池级勉强转正（+0.54%）但每票仅 1.2 笔 | 交易枯竭，且 600176 在 92 阈值下 0 笔交易 |
| ER 自身分位（时序替代横截面） | 池级 ≥85 最优 +0.68%，但 600176 照样漏掉大盈利 | 两笔大盈利买入时 ER 绝对值仅 0.08~0.11，在自身历史分位也 <70 |
| 两极闸门（ER≥90 ∪ ER≤40） | 600176 +195.81% 但池级全负 | 混沌突破是单票特例，不具池级普适性 |
| Δ5ER 金叉直接买入 | 600176 +36%~+103% 但回撤 -40%+；池级 -17.82% 灾难 | 假信号率 67%，池级被噪声淹没 |
| Δ5ER 死叉卖出 | 600176 +214%→+2.21% | ER 回落≠趋势结束，死叉在趋势中段就触发，利润全砍 |
| 平移 BBI12 提前预判拐点（方向A） | k 越大越差 | 噪声放大，交易数 5.0→9.2 |
| 30min 短周期辅助（方向C） | 同窗对照完败 1H | 短周期噪音更大 |
| 卡尔曼融合 SSA mid 因果 | 追平未超越 BBI12 | 反方差融合对预测/测量标签对称 |
| 非因果 SSA（+471%） | 不可复制 | 未来信息溢价 |

## 6. 核心认知（调试时牢记）

1. **卖出层是收益/回撤的主战场**：本策略的突破来自把「峰顶确认卖」（滞后）改为「止盈8%先到先卖」，而不是买入层叠加闸门
2. **止损（固定价）与趋势票互斥**：0% 跌破买入价止损会把强趋势票的小时级回调全部打成止损出场，然后只能等下个拐点再进，错过主升
3. **ER 的正确用法是 Δ5ER 方向过滤，不是 ER 水平闸门**：测「ER 正在急降」比测「ER 处于高位」有用得多
4. **Δ5ER 金叉是有价值的领先指标但只能做预警**：平均领先拐点 6.4 根、金叉价更低，但假信号 2/3
5. **池级与单票的矛盾是结构性的**：任何池级减亏的过滤器都会在强趋势票上误杀，双模式就是给用户这个选择权

## 8. 后续调优方向（未验证，按优先级）

1. **止盈参数自适应**：强趋势票 8% 可能偏紧，可按持仓期间 ATR 或 ER 水平动态放宽（如 ER>0.3 时放宽到 12%）
2. **稳健阈值 -0.05 的再校准**：后半段偏弱提示可能需要随市况调整
3. **金叉预警 → 实盘验证**：观察预警后 6 根内拐点出现率，若显著高于 33% 可升级为买入信号
4. **池级负期望问题**：本策略池级均值仍在 0 附近，选股端（哪些票适合此策略）比策略本身更值得优化——强趋势特征（如 600176 的历史 ER 结构）可作为选股前置条件
