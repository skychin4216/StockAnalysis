# 做T時段權重策略

> 實作檔案：`TTimeSlotStrategy.kt` / 整合於 `TSignalSynthesizeNode`

---

## 設計理念

做T本質上是超短線（1天）的極致應用——借助底倉在一天內完成「先買後賣」或「先賣後買」，賺取差價、降低成本。

核心洞察：**不同時間段，操作方向完全相反**。傳統的「一次性分析」無法捕捉日內時段特徵，因此引入時段權重調整器。

---

## 七個關鍵時間段

### 一、兩種做T模式

| 模式 | 操作順序 | 適用場景 |
|------|---------|---------|
| 正T（先買後賣） | 開盤先低吸 → 盤中沖高賣出底倉 | 預計股價低開或盤中會探底回升 |
| 倒T（先賣後買） | 開盤先高拋 → 盤中回落再接回 | 預計股價高開或盤中會沖高回落 |

### 二、時間段詳解

#### ⏰ 9:30 - 9:40（早盤衝高 · 跑）

- **特徵**：散戶跟風最踴躍，主力利用少量資金拉高誘多
- **操作**：高拋為主，忌追高！急拉超過5%且量能衰減 = 主力出貨信號
- **權重**：正T -25 / 反T +20 / 置信度 90%

#### ⏰ 9:50 - 10:10（短期高點 · 跑）

- **特徵**：第一輪博弈結束，獲利盤和跟風盤都已進出，容易形成日內短期高點
- **操作**：適合高拋（倒T賣點），見好就收
- **權重**：正T -15 / 反T +15 / 置信度 85%

#### ⏰ 10:10 - 10:40（主力動向 · 看）

- **特徵**：真正的主力決定今天是否「幹活」的時間。穩步拉升+資金流入 = 可持有；無動靜 = 震盪或下跌
- **操作**：觀察期，決定去留
- **權重**：正T -5 / 反T -5 / 置信度 70%（降低所有信號）

#### ⏰ 10:40 - 11:10（上午正常時段）

- **特徵**：正常交易時段，無特殊偏向
- **操作**：按機構意圖和技術指標正常判斷
- **權重**：正T 0 / 反T 0 / 置信度 100%

#### ⏰ 11:10 - 11:30（午盤收盤 · 防）

- **特徵**：臨近午盤直線拉升大概率是「做圖」給下午看，吸引跟風盤
- **操作**：急拉別跟，謹防中招！除非極度強勢，否則持續性很差
- **權重**：正T -20 / 反T +10 / 置信度 80%

#### ⏰ 13:00 - 13:30（午後開盤 · 防）

- **特徵**：脈衝式拉升大概率誘多，快速下跌反而是日內相對低點
- **操作**：警惕「開盤殺」，13:15-13:30 容易走出當日高點
- **權重**：正T -15 / 反T +10 / 置信度 85%

#### ⏰ 13:30 - 14:00（垃圾時間 · 等）

- **特徵**：多空平衡，主力洗盤或準備下午大動作
- **操作**：看戲為主，別激動，別下單
- **權重**：正T -10 / 反T -10 / 置信度 60%（大幅降低）

#### ⏰ 14:00 - 14:30（方向選擇 · 盯）

- **特徵**：全天最關鍵時段。股價回落 = 全天走弱；資金搶籌 = 次日還有行情。游資常偷襲漲停
- **操作**：關鍵轉折，謹慎觀察
- **權重**：正T +10 / 反T +10 / 置信度 100%

#### ⏰ 14:30 - 15:00（定調時刻 · 決）

- **特徵**：最重要的轉折點，決定明天走勢。強勢 = 繼續拉高為明天出貨做準備；弱勢 = 沖高回落誘多
- **操作**：尾盤直線拉升不要激動，很可能是做帳或騙線
- **權重**：正T +15 / 反T +15 / 置信度 110%（增強強信號）

## 風險提示

- T倉當曰了結，不變成加仓
- 做錯T不戀戰，按原止損線處理
- 分時背離只管短期（一二十分鐘或日內一兩個小時）
- 切忌貪心，有幾個點的差價便已足夠
- 震盪市或高波動行情中做T效果最佳

## 程式化實現

### TTimeSlot enum

將全天劃分為 10 個時段（含 NON_TRADING），每個時段定義：
- `tBuyAdjust`: 正T分數調整
- `rtSellAdjust`: 反T分數調整
- `confidenceScale`: 置信度縮放因子
- `actionHint`: 中文操作提示

### TTimeSlotAdjuster

在 `TSignalSynthesizeNode` 信號合成時調用：
1. 根據 `LocalTime.now()` 獲取當前時段
2. 對每個信號施加時段分數調整
3. 乘以置信度縮放因子
4. NON_TRADING 時段直接過濾（不產生信號）

### 輸出

- 日誌：`⏰ 當前時段: 早盤衝高 | 正T調整: -25 | 反T調整: +20 | 置信度縮放: 90%`
- 推薦記錄：`[置信度65%|機構:震倉洗盤|🏃早盤衝高] ...`
- `TSynthesizeResult.timeSlotLabel` / `timeSlotHint` 供 UI 顯示
