# 预警页 · 融合策略多选 + 拐点核对图

## Context（为什么做）

上一轮把预警页的拐点策略口径从「误用的 BBI 多空指标」纠正为「BB 布林极限」，
并在测试层做了 BB vs BBI 的受控 A/B。结论：

- **保真度**：只有新 BB 口径能复现用户在 600176 图上看到的 2026-08-25 11:30 谷底；旧 BBI 复现不出。
- **业绩**：旧 BBI 更平滑（交易笔数约为 BB 的 1/3、均持仓 19.9 根 vs 5.2~8.7 根），本窗口超额更高；
  新 BB 更灵敏（出场更早、亏损笔均亏更小、胜率更高），代价是交易更密、超额更低。
- **测试层融合网格**（12 只 × 末 480 根 1H）证明「BB 管出场、BBI 管入场」确实能同时拿到
  「早避跌」（均亏幅收窄到 −0.98~−1.23%）与「低噪声」（笔数 5.7~10.2）。

用户决定：把 3 条融合/纯口径策略**做进 App**，与现有 BASE、BB 拐点一起**5 项多选**，
并新增一张**拐点核对图**（单图双轴 + 拐点清单表），用于与看盘软件逐点核对。

## 目标

1. 预警页策略改为 **5 项可分别勾选**（多选，勾谁算谁，各出一张结果卡）。
2. 新增 **拐点核对图**：一张 CombinedChart 双 Y 轴 + 一张拐点清单表。
3. 引擎侧提供一次调用同时算出 BB / BBI 两侧序列与 3 条融合策略的 API。
4. **不动** BASE 多指标语义、不动浮窗/一键更新链路。

## 策略清单（5 项）

| id | 显示名 | 计算入口 |
|----|--------|----------|
| `BASE` | 多指标共振（JAX/OBV/KDJ/WR/BBI） | `SsaAlertEngine.analyze`（现状不变） |
| `BBPIVOT` | BB 布林极限拐点（16 种平滑口径对比） | `SsaBbiPivotEngine.run`（现状不变） |
| `PURE_BBI12` | 纯 BBI12 拐点（最平稳） | 新增 `runMix` |
| `MIX_OR` | 融合 · BBI12底→(BB6∪BBI12)顶（先到先出） | 新增 `runMix` |
| `MIX_BBWIN` | 融合 · BBI12底→BB6顶·BB窗（笔数最少） | 新增 `runMix` |

默认勾选：`BASE`。

## 改动清单

### 1. 引擎 `app/src/main/java/com/chin/stockanalysis/strategy/ssa/SsaBbiPivotEngine.kt`

新增（全部放在 object 内，复用现有私有成员，**不改现有 `run`/`runTuned`/`runCross`/`runWr` 行为**）：

- `enum class MixMode(val label: String)`：`PURE_BBI12` / `BBI12_BB6_OR` / `BBI12_BB6_BBWIN`。
- `data class MixResult(mode, signals: List<Signal>, perf: AlertPerf, trades: List<Trade>)`
- `data class MixBundle(bars, windowFrom, bb, bbMa6, bbi, bbiMa12,
  bbPivots: List<Signal>, bbiPivots: List<Signal>, results: List<MixResult>, baseline: AlertPerf)`
- `fun runMix(bars: List<Bar>, window: Int = 120,
   modes: List<MixMode> = MixMode.values().toList(), p: AlertParams = AlertParams()): MixBundle`

`runMix` 实现要点（复用现有私有函数）：
- `val (bb, bbMa6) = bbSeries(closes, 6)`；`val (bbi, bbiMa12) = SsaAlertEngine.bbiSeries(closes, 12)`
- `bbPivots = pivotSignals(bars, smoothOf(Smooth.MA6, bb), Smooth.MA6)`
- `bbiPivots = pivotSignals(bars, smoothOf(Smooth.MA12, bbi), Smooth.MA12)`
- 各 mode 组合信号（**与测试层已跑出口径逐字一致**）：
  - `PURE_BBI12` = `bbiPivots` 全量；闸门 = `allOpen`
  - `BBI12_BB6_OR` = `bbiPivots.buys + (bbiPivots.sells ∪ bbPivots.sells)`；闸门 = `allOpen`
  - `BBI12_BB6_BBWIN` = `bbiPivots.buys + bbPivots.sells`；闸门 = `buyWindowSeries(bb, bbMa6)`
  - 信号列表按 `index` 升序
- 逐条 `simulate(bars, sigs, win, from, to, 0.0, p)` → `MixResult`
- `baseline` = `SsaAlertEngine.computePerf(bars, analyze(bars).signals, analyze(bars).buyWindowOpen, from, to, p)`
