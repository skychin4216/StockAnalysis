# 底部反转形态 · Reversal Bottom Pattern

完整方法论见 `smalltools/_reversal_patterns.py`。本 SKILL 只给执行骨架。

## 触发场景
- "双锤子抄底"（光迅科技 2026-09-15 案例：连跌 + 09-11 放量锤子 + 09-14 缩量锤子 + 09-15 回踩双底 167.59 不破）
- "找底部反转形态的票"、"哪些票已经见底"、"形态确认可抄底"
- 与 `_oversold_alert`（接飞刀预警，仍在阴跌）**区别**：本 skill 是「形态反转确认」——已经有反转信号，可下手

## 六种形态（2026-09-16 上线）

| 标签 | 名称 | 核心判定 | 场景 |
|---|---|---|---|
| **R1** | 双锤子反转 | 连续阴跌 ≥3 天 + 第一根放量锤子 + 第二根缩量锤子（vr 较第一根≤70%）+ 当日不破双底 | **最经典**（光迅案例） |
| R2 | 早晨之星 | 长阴 + 十字星 + 长阳（前三根） | 教科书底部形态 |
| R3 | 看涨吞没 | 阴 + 大阳包阴（实体覆盖 ≥30%） | 强反转 |
| R4 | 底部岛形 | 向下跳空 → **≥3 根窄幅平台(振幅≤10%)** → 向上跳空（平台不得突破缺口上沿、无单日>9%） | 结构性反转 |
| R5 | V 形底 | 8 根内**先**跌 ≥-15% **后**反弹 ≥+8%（最低点须在窗口后半段，argmin≥3） | 急跌急涨 |
| R6 | 圆弧底 | 60 日内低点先降后抬 + 振幅先收后放 | 中期底部 |

## 锤子/十字线判定口径（`_is_hammer`，关键）

光迅 09-11/09-14 都是**长下影阴锤子**，必须放宽口径才能识别：
- 标准锤子：上影 ≤30% 振幅，下影 ≥2× 实体（收阳）/ ≥3× 实体（收阴）
- 长腿十字线：实体 ≤30% 振幅，上下影都 ≥1.5× 实体，**且上影 ≤ 2× 下影**（对称性）
  - 关键：不加上影约束会把**流星线/射击之星**（上影长下影短，看跌）误判为底部反转
  - 教训案例：锦浪科技 09-04 上影 1.24 / 下影 0.29（4.3 倍），曾被误判
- 「近 10 日低区」**不作必要条件**（下跌中继的下影短，反转的下影长——用下影长度反推即可）

4. 推送群已自动接入（15:10 收盘总结 + 当日 11:31 午间总结末尾会自动追加「🔁 底部反转形态」段）

## 形态判定阈值（`score`）
- R1 双锤子：4.5 + min(连跌-3, 2)×0.4 → **4.5~5.3（最高优先级）**
- R2 早晨之星：4.0
- R3 看涨吞没：3.5
- R4 底部岛形：3.5（2026-09-16 从 5.0 降——A股跳空常见，688只中曾39命中，两轮收紧后仍22只，误报率高于 R1）
- R5 V 形底：3.0
- R6 圆弧底：3.5
- 多重命中：每个额外 +0.5（思源电气 R3+R4 = 4.0）
- 阈值默认 3.0 推送，4.0 视为「强信号」

## 关键红线
- **不是万能**：形态命中≠必涨；短线需结合大盘环境（熊市/震荡市胜率<牛市）
- **光迅案例（用户 2026-09-15 实际买入 168）**：双锤子反转 score=4.5；后续反弹需关注 BOLL 中轨（172 主力成本）和 J 值（KDJ）确认强度
- **多形态组合可信度更高**：吞没+岛形（思源电气 4.0）等组合优于单形态
