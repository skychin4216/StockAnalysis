# 选股思路 · Sector Picks

完整方法论见 `docs/选股思路.md`。本 SKILL 只给执行骨架。

## 触发场景
- "农业板块怎么选股""草甘膦看哪几只""这板块谁弹性大"
- 每日三次推送的下游步骤：把 sector-hunter 输出的 Top 板块转成个股清单

## 执行 SOP（一页纸）
1. 板块已验证（生命周期 ≤ 鱼身）后圈候选池：正宗龙头 + 弹性小票两梯队各 2-4 只；
2. 拉数据（东财不可达时的腾讯兜底链路）：
   - `qt.gtimg.cn/q=sh600598,sz000998,...` 批量实时 → f32涨跌% / f38换手 / f44流通市值 / f45总市值 / f46 PB / f49量比 / f53静态PE；
   - `from backtest_guangmo import fetch_tencent; fetch_tencent(secid,"20260425","20260909")` 日K → 5/10/20日涨幅、MA20/60、距60日高点；
3. 六维过滤（详见文档）：
   - 卡位：涨价→利润增厚占市值弹性（产能×0.1亿/每涨1千元）；
   - 财务粗筛：存贷双高/商誉>30%/质押>50%/扣非背离 → 直接排除；
   - 估值：市值 80-300 亿优先；周期股静态PE<25 & PB<2.5；破净加分；**PE 失真四拆解**（北大荒 Q4 季节失真→看静态）；
   - 资金：主力净流入窗口 + 量价（放量突破/缩量回踩）；
   - 形态：多头排列 + 20日涨幅<50%（防鱼尾）→ 给低吸区；
   - 大盘：空头/纠缠 → 总仓 ≤3 成、单票 ≤1.5 成、只低吸不追高。
4. 输出个股卡 ×3-6 只（格式见文档 §7），含低吸区/止损线/证伪线/数据截至与口径 + 免责。

## 关键红线
- **先板块后个股**：板块逻辑证伪（价格跌破锚）个股无条件退；
- **鱼尾识别**：20 日涨幅>50%、龙头 PB>5 或 PE 失真到数百倍 → 只做快反或不推；
- 周期股顶部"低 PE 陷阱"、底部"PE 高是常态"——用 PB 与成本线而非 PE 单点判断；
- 动态 PE 为负先拆因（亏损/季节性/一次性/高基数），不裸用。
