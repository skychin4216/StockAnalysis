回测区间 2026-03-06 → 2026-10-16（1H，100 只票）· 信号 = BBI12 拐点 · ER = Kaufman 效率比(60) · 全部决策因果（只用 ≤ 上一根）

一、规则规格（可回测口径）

  • 信号层（单票）：BBI = (MA3+MA6+MA12+MA24)/4，拐点线 = SMA(BBI,12)。谷底确认（line[i]≤line[i-1] 且 line[i+1]>line[i]）→ 买；峰顶确认 → 卖。信号根 = 确认根 = i+1，成交价 = 该根收盘。
  • 票性路由层（跨票、因果）：ERi = |C_i−C_{i−60}| / Σ|ΔC|。每根 bar 只把资金等权分给「持仓中 且 ER 处于横截面高位」的票；其余持仓票空仓等待。决策用 ER[i-1]（用 ER[i] 会引入前视偏差）。
  • 参数：横截面分位阈值 P70（推荐）或 top-N=10；W=60；回测段 = 末 900 根的 [300,899]（前 300 根做 ER 预热）。
  • 逐票变体（已证伪的用法）：V1 票性仓位 = 按票性 ER 给 0.25~1.0 权重；V2~V4 = 仅「趋势态」建仓 / 加后期禁入。

BBI12 的买点本身是「反转买点」，此时 ER 天然偏低；按「ER 高才买」过滤会滤掉多数买点（持仓 43%→9%），收益归零。V1 仓位不改变收益、只压回撤。→ 逐票闸门方向错误。

五、结论

  • 有效用法 = 跨票选择，不是逐票择时：同一批 BBI12 信号，加上「只做横截面 ER 高位」后，组合收益 9.57% → 28.97%，夏普 1.12 → 2.32，回撤基本持平。
  • 稳健：三段（各 200 根）里 ER 选择段段不劣于全池；阈值 P40~P80、N8~N30 全部有效。
  • 逐票闸门证伪：V2~V4 收益≈0；V1 只改善风险。ER 与 BBI12 反转买点节奏相反。
  • 口径说明：BBI12 与 Kotlin 引擎复现校验 396/400 一致（最大偏差 0.93%）；已修正 ER[i] 前视偏差；样本为 100 只存活大票（存在幸存者偏差），单一 11 个月区间。
